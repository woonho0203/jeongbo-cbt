## 1. 심판 대상 조항

- 검수 절차에 PDF 표-텍스트 평탄화 후보 확인과 회귀 조건을 추가한 부분
- 이미지표 채점표에 원본 표 평탄화 치명 오류와 후보 판정 체크리스트를 추가한 부분
- PDF 매핑 고시에 행·열 자료의 `stem`·`options` 줄글 평탄화 금지와 정상 예외 기록 기준을 추가한 부분
- 자동점검 고시에 `scripts/audit_plaintext_table_candidates.js` 실행 명령과 `--show-known` 조회 명령을 추가한 부분
- 실제 데이터 후보 5건을 PDF 렌더로 대조하고, 2017-2 Q26·2017-3 Q28을 수정한 부분

## 2. 쟁점

1. PDF 표 또는 구조화 자료가 JSON에서 줄글로만 들어간 사각지대를 자동 후보화하는 규칙이 헌법의 데이터 무결성 원칙에 맞는가.
2. 후보를 즉시 오류로 확정하지 않고 PDF 대조 후 복원/예외로 나누는 절차가 원본 보존 원칙과 충돌하지 않는가.
3. 새 규칙이 올바른 계층에 배치되었는가.

## 3. 판단

### 3.1 위헌 여부

위헌 사유 없음.

- 헌법의 1순위인 데이터 무결성을 강화한다.
- 문제 원문·보기·정답을 원본 대조 없이 임의 변경하지 않고, 후보를 PDF 대조 큐로만 올리도록 했다.
- `table` 강제 원칙이 아니라 정상 예외 기록을 허용해 원본 재현과 가독성의 균형을 유지한다.

### 3.2 계층 적합성

계층 배치 적합.

| 내용 | 배치 | 판단 |
|---|---|---|
| 후보 확인·회귀 절차 | 시행령 | 작업 순서·단계 이동 조건이므로 적합 |
| 치명 오류·체크리스트 | 시행규칙 | 점수표·판정 기준이므로 적합 |
| 실행 명령·스크립트 이름·예외 조회 옵션 | 고시·scripts | 명령·도구·설정값이므로 적합 |
| 실제 실행 결과 | 운영기록 | 검수보고로 분리되어 적합 |
| 심판 결과 | 결정례 | 헌법재판소법 제10조에 따라 적합 |

### 3.3 충돌 여부

중대한 충돌 없음.

- 기존 제4조의3(지문-표 중복 탐지)은 `table`이 이미 있는 경우를 다루고, 새 제4조의5는 `table`이 없는 평탄화 후보를 다루므로 역할이 분리된다.
- 기존 제4조의4(자료 필요 문항 image/table 누락 후보)는 "다음 표/그림" 같은 명시 단서를 주로 보며, 새 점검은 행·열 형태와 값 나열을 후보화하므로 보완 관계다.
- 고시_추출삽입_PDF매핑 v1.4의 정상 예외 조항은 무조건 `table` 강제와 충돌하지 않도록 PDF 대조·운영기록 근거를 요구한다.

### 3.4 실측 검증

- `node scripts/audit_plaintext_table_candidates.js`: 미확인 후보 0건
- `node scripts/audit_plaintext_table_candidates.js --show-known`: 확인 완료 정상 예외 4건
- PDF 렌더 대조 완료:

  - 2017-3 Q28: 표는 아니나 첨자 OCR 손상 → 수정 완료
  - 2018-2 Q30: 표 아님
  - 2019-2 Q94: 표 아님
