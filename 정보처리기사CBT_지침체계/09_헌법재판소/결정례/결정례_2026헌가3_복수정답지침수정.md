# 결정례_2026헌가3_복수정답지침수정

## 0. 사건 정보

- 사건번호: 2026헌가3 (가: 위헌/계층 심판)
- 심판 종류: 위헌심판 + 계층적합성심판 + 충돌심판 (지침 수정 직후 자동 심판, 헌법재판소법 제4조)
- 심판 대상: 데이터관리법 v1.0.1(제2조 6호·제3조 5호), 자동점검명령 고시 v1.2(제1조), 판례_실패_복수정답오탐_002
- 심판 개시 사유: 자동 (실데이터 검수 중 지침 수정 발생)
- 결정일: 2026-07-11
- 사건 상태: 종결

## 1. 심판 대상 조항

1. 데이터관리법 제2조 6호(신설): `answer`는 정수 또는 배열(전항정답·복수정답).
2. 데이터관리법 제3조 5호(개정): 배열 원소 전부 1..options 범위.
3. 자동점검명령 고시 제1조(개정): 배열 answer 허용 점검 로직.

## 2. 쟁점

정상 데이터(공식 복수정답 배열)를 결함으로 오탐한 지침을, 데이터 사실에 맞게 수정한 것이 헌법·계층 질서에 부합하는가.

## 3. 판단

- **위헌 여부**: 없음. 수정은 헌법 제3조(원문 충실성·앱 무결성)와 제5조(정답은 PDF 대조 후에만 변경)를 오히려 강화한다. 데이터 정정이 아니라 데이터를 오탐하던 지침을 정정한 것이므로 헌법 제5조 위반 없음.
- **계층 적합성**: 정답 필드의 형식·정의는 법률(데이터관리법), 점검 명령 로직은 고시(자동점검명령)에 배치 — 제8조 판정표 부합. 점수표·절차 변경 없음.
- **충돌 여부**: 법률(제2조 6호)이 배열을 정의하고 고시(제1조)가 이를 점검하도록 정합. 헌법 제5조("answer 임의 변경 금지")와 충돌하지 않음 — 배열 허용은 형식 정의이지 변경 허가가 아니다. 앱 실제 동작(`isCorrectAnswer` 배열 처리)과도 일치.
- **참조무결성**: 라우터·검수보고의 자동점검 고시 참조를 v1.2로 갱신 완료.

## 4. 주문

데이터관리법 v1.0.1, 자동점검명령 고시 v1.2, 판례_002는 모두 **합헌**이다. 즉시 효력.
