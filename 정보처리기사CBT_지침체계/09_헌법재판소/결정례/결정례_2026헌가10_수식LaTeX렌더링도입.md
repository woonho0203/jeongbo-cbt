# 결정례_2026헌가10_수식LaTeX렌더링도입

- 사건번호: 2026헌가10
- 심판 종류: 위헌심판 + 계층적합성심판 + 충돌심판 (기존 지침 수정) + 이행확인심판
- 심판 대상:

  - `public/index.html` KaTeX 스크립트·스타일시트 태그 추가
  - 05_고시_훈령_예규/고시_해설_해설형식_유형별템플릿 v1.1→v1.2 (제2조의3 신설)
  - data 8문항 LaTeX 표기 전환 (exam_2016-2 Q32, exam_2019-1 Q26·Q36·Q90, exam_2017-1 Q23·Q34·Q84, exam_2019-2 Q96)
- 심판 개시 사유: 자동 (기존 지침 수정 직후) + 사용자 청구("지침에 반영")
- 결정일: 2026-07-21
- 사건 상태: **종결**

## 1. 심판 대상 조항

사용자가 "수식을 사람이 읽기 쉽게 LaTeX로 예쁘게 표시해달라"고 요청함에 따라, 앱에 KaTeX 렌더링을 도입하고 판례_007로 복원한 문항 중 수식이 포함된 8문항의 표기를 LaTeX로 전환한 조치 전체.

## 2. 쟁점

1. 서드파티 라이브러리(KaTeX)를 앱에 정적으로 내장하는 것이 헌법 제3조(앱 무결성)에 위배되는가.
2. 신설 조항(고시 제2조의3)이 올바른 계층에 있는가.
3. 8문항의 `options`·`explanation` 표기 변경이 헌법 제5조 1호(원문 대조 없는 변경 금지)에 저촉되는가.
4. exam_2017-2 Q28(판례_007 복원 대상에 포함되어 있던 문항)을 이번 전환 대상에서 제외한 것이 타당한가.

## 3. 판단

- **위헌 여부: 없음.**
  - KaTeX는 `npm pack`으로 내려받아 `public/vendor/katex/`에 정적 파일(js·css·woff2)로 내장했다. 외부 CDN에 의존하지 않아 네트워크 장애·서드파티 변경에 영향받지 않으며, 서버(`server/index.js`)의 기존 정적 파일 서빙 로직만으로 동작해 별도 인프라 변경이 없다.
  - `renderMathIn()`은 `$...$` 델리미터를 찾아 화면 표시만 바꾸는 렌더링 계층 함수로, `stem`·`options`·`answer` 데이터 자체를 변경하지 않는다. `remapExplanationNumbers()`(보기 번호 재매핑)와는 독립적으로 동작하며 실측 결과 서로 충돌하지 않는다(3-4항 참조).
  - 8문항 표기 변경은 판례_007·결정례_2026헌가9로 이미 PDF 대조·유권해석을 거쳐 확정된 수학적 값을, 문법만 LaTeX로 다시 쓴 것이다(예: `A̅+B̅` → `\overline{A}+\overline{B}`, 값과 의미는 동일). 새 규칙(제2조의3 제4항)에 "표기 변경은 원문 대조 재실행이 불요하다"는 기준을 명문화해 판단 근거를 남겼다.
- **계층 적합성: 오배치 없음.**
  - 수식을 어떻게 표기할 것인가(LaTeX 사용 기준·한글 제약·기존 표기 유지 기준) → 형식·템플릿이므로 고시. 기존 제2조의2(보기 번호 표기)와 같은 성격이라 같은 문서에 조항으로 추가했다.
  - 앱 코드(KaTeX 도입)·라이브러리 벤더링은 지침 체계의 계층 대상이 아니라 **규율 대상(산출물)**이며, 고시가 규칙을 정하고 코드가 이를 구현하는 구조라 계층 혼선이 없다.
- **충돌 여부: 없음.** 제2조의2(보기 번호 재매핑)와 제2조의3(수식 LaTeX)이 같은 해설 텍스트 안에서 함께 동작해야 하므로, 제2조의3 제5항에 상호 안전 규칙(수식은 `$`로 닫히므로 `N번` 정규식과 부딪히지 않되, 수식 바로 뒤에 `번`을 붙이지 않는다)을 명문화해 사전에 충돌 가능성을 제거했다.
- **exam_2017-2 Q28 제외 판단**: 이 문항은 `MPLOPS = (수행시간×10⁶) / 프로그램 내의 부동소수점 연산개수`처럼 분수의 분자·분모가 통째로 한글 구(句)다. 제2조의3 제2항(한글은 수식 밖에 둔다)에 따라 LaTeX로 감쌀 수 없고, 이미 유니코드 위첨자(`10⁶`)로 정상 표시되고 있어 전환 실익도 없다. 전환 대상에서 제외하고 그 근거를 고시 제2항 예시와 이 결정문에 기록해, 향후 유사 문항(한글 비중이 큰 "A를 B로 나눈 값" 서술)을 LaTeX로 감싸려 시도하지 않도록 한다.
- **이행확인심판**: 실제 로컬 서버(포트 3000)를 띄워 브라우저로 검증했다.
  - 8문항에서 추출한 LaTeX 수식 50종 전체를 `katex.renderToString(..., {throwOnError:true})`로 실행해 파싱 오류 0건을 확인했다.
  - exam_2017-1 Q23을 실제로 풀어 옵션 4개가 모두 KaTeX로 렌더링됨을 확인했고, 보기를 클릭해 해설이 열렸을 때 `remapExplanationNumbers()`가 LaTeX 델리미터(`$...$`)와 섞인 텍스트에서도 "정답은 1번" → "정답은 2번"처럼 셔플된 순서에 맞게 정확히 재매핑됨을 실측했다.
  - exam_2016-2 Q32(오버라인 문항)에서 옵션 4개 모두 `\overline{}`가 정상 렌더링됨을 `.katex` 클래스 개수(4개)로 확인했다.
  - 렌더링 트리거는 `#app`에 대한 `MutationObserver` + `setTimeout` 디바운스로 구현했다. 최초 구현에서 `requestAnimationFrame`을 썼을 때 비활성/백그라운드 탭에서 콜백이 지연되어 렌더링이 누락되는 결함을 검증 중 발견해 `setTimeout(fn, 0)`으로 교체하고 재검증했다.
  - 캐시버스터(`?v=`) 미갱신 상태에서는 브라우저가 이전 스크립트를 계속 서빙해 수정이 반영되지 않는 것도 확인해, 로컬 검증 시에도 `scripts/bump_version.js` 실행이 필요함을 확인했다(기존 버전 관리 체계와 정합).
- **심판 점수**: 합헌성 30 / 계층적합성 30 / 무충돌성 20 / 형식적합성 10 / 참조무결성 10 — **총 100점**

## 4. 주문

KaTeX 렌더링 도입과 고시 v1.2 제2조의3, 8문항 LaTeX 표기 전환은 **합헌**이다.

## 6. 재발 방지 기준

수식 LaTeX 전환은 "텍스트로 정확히 표현되지 않는 순수 기호 수식"에만 적용한다. 한글이 절반 이상을 차지하는 서술형 수식(비율·정의를 한글로 풀어 쓴 문장)은 LaTeX로 감싸지 말고 기존 표기를 유지한다 — KaTeX 내장 폰트가 한글 글리프를 지원하지 않아 억지로 감싸면 렌더링이 깨진다. 이 판단 기준(제2조의3 제2항)을 어기면 표시 결함이 재발한다.
