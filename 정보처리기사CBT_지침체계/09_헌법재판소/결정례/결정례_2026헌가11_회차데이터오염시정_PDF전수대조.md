## 1. 심판 대상 조항

전체 34개 데이터 파일을 각자의 PDF 원본과 자동 교차 대조해 `exam_2022-1.json`이 `exam_2022-2.json`의 내용을 examId만 바꿔 담고 있었음을 발견하고, PDF에서 직접 재추출해 시정한 조치 전체.

## 2. 쟁점

1. `stem`·`options`·`answer`(데이터관리법 제2조 3호의 **불변 필드**) 100문항을 통째로 교체한 것이 헌법 제5조 1호(원문 대조 없는 임의 변경 금지)에 저촉되는가.
2. 새로 신설한 제1조의3(회차 원본 대응 점검)이 다른 조항과 달리 순수 Node 명령이 아니라 Python·PDF 원본을 전제하는데, 이것이 고시의 "하급 모델이 판단 없이 그대로 실행" 원칙(고시 0절)과 충돌하는가.
3. 정답 100개·해설 100건을 새로 작성한 것의 신뢰성을 어떻게 검증했는가.

## 3. 판단

- **위헌 여부: 없음.**
  - 헌법 제5조 1호가 금지하는 것은 "PDF 원본 대조 없이" 불변 필드를 바꾸는 행위다. 이번 조치는 실제 PDF(`2022년1회_기사필기 기출문제.pdf`)를 열어 2열 레이아웃을 좌우로 분리한 단어 좌표 기반 추출로 100문항 전부를 다시 뽑고, 정답표 페이지의 `1.④ 2.② ...` 형식을 파싱해 100개 정답 전부를 대조했다. 오히려 **원문 대조 자체가 이번 조치의 핵심**이라 절차를 충족한다.
  - 더 근본적으로, 교체 이전의 `exam_2022-1.json` 값은애초에 "PDF 원본과 대조된 정상 데이터"가 아니라 다른 회차의 오염된 복사본이었다. 헌법 제5조 1호는 정상 원문의 임의 변경을 금지하는 조항이지, 오염이 확인된 값을 원본과 대조해 정정하는 것까지 막지 않는다.
  - 보기가 다이어그램·표·프로그램 출력인 3문항(Q44·Q57·Q79)은 고배율 시각 판독을 거쳤고, 이 중 Q44는 동일 문항이 exam_2017-1 Q19에 이미 정상 등록돼 있어 표기(마름모/직사각형/이중타원/밑줄)를 상호 대조까지 했다.
- **계층 적합성: 오배치 없음, 단 실행 조건의 예외를 명시**
  - 회차-원본 대응 점검은 검수 명령이므로 고시 배치가 맞다. 다만 기존 제1~4조·제2조들은 전부 `fs`만 쓰는 순수 Node 스니펫으로 하급 모델이 판단 없이 그대로 실행 가능한데, 제1조의3은 Python·`pdfplumber`·로컬 PDF 폴더가 있어야 실행된다. 이 차이를 숨기지 않고 조문 서두에 "권장 절차이며 하급 모델이 그대로 복붙 실행할 수 있는 명령은 아니다"라고 명시해 고시 0절의 전제(하급 모델 그대로 실행)와 충돌하지 않도록 범위를 한정했다. 판단이 필요한 3단계(자기 일치율 낮은데 다른 PDF와도 안 맞는 경우 오염이 아니라 구조적 원인으로 볼지)는 상급 모델 판단 영역으로 명시했다.
- **충돌 여부: 없음.**
- **이행확인심판**: 실제로 실행해 확인했다.
  - 재추출 100문항의 정답을 PDF 정답표 텍스트와 프로그램으로 전수 대조해 100/100 일치를 확인했다.
  - 재작성한 100건 해설에 제2조의2·제2조의3(무맥락 템플릿) 자동 탐지를 실행해 히트 0건을 확인했다.
  - 고시 제1조(필수 필드)·제1조의2(보기 구별)·제4조의2(24순열 셔플 재매핑)를 전체 3,568문항에 재실행해 전부 통과(제1조의2의 6건은 전부 기존에 문서화된 "공백이 정답 근거" 예외와 동일 패턴임을 확인)를 확인했다.
  - 로컬 서버에서 실제로 문제를 풀어 Q1(User Interface 지침), Q44(E-R 다중값 속성), Q57(UNION ALL 결과표 이미지), Q79(Python 반복 출력) 화면 렌더링을 확인했다.
  - 자체 검수 중 "~틀린 설명이라 정답은 N번이다" 패턴의 정상 해설 9건이 제2조 정규식에 오탐되는 것을 발견해 그 자리에서 `틀린` 토큰을 추가하고 재검증했다.
- **심판 점수**: 합헌성 30 / 계층적합성 28(Python 의존 예외 명시로 감점 최소화) / 무충돌성 20 / 형식적합성 10 / 참조무결성 10 — **총 98점**

## 4. 주문
