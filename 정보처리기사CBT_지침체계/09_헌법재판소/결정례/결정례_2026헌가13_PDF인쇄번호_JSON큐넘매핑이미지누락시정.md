## 1. 심판 대상 조항

PDF 자료 삽입 시 PDF 인쇄 번호와 JSON `qnum`이 다를 수 있음을 명시하고, `stem` 핵심 문구로 보정 매핑하도록 법률·시행령·시행규칙·고시에 나누어 반영한 조치. 또한 `stem`이 "다음 트리/그림/표"처럼 자료를 전제로 하는데 `image`·`table` 필드가 모두 없는 후보를 자동점검으로 잡도록 고시 제4조의4를 신설했다.

## 2. 쟁점

1. Q5에 새 이미지를 추가한 것이 헌법 제5조 1호(원문 대조 없는 임의 변경 금지)에 저촉되는가.
2. PDF 인쇄 번호와 JSON `qnum` 불일치 보정 규칙을 법률·시행령·시행규칙·고시에 나누어 둔 것이 계층상 적합한가.
3. 고시 제4조의4가 후보 목록화 과정에서 정상 문항을 오탐할 수 있는데, 이것이 지침 충돌 또는 과도한 실패 판정인지.
4. 파일명은 PDF 인쇄 번호 `10`이 아니라 JSON Q5 기준 `2016-1_q5.png`로 저장하는 것이 데이터관리법과 충돌하지 않는가.

## 3. 판단

- 위헌 여부: 없음.
  - Q5 이미지는 원본 PDF에서 직접 크롭했고, 문제 원문·보기·정답은 변경하지 않았다. 이는 불변 필드 임의 변경이 아니라 자료 필드(`image`) 보완이다.
  - 파일명은 고시_데이터_JSON스키마_파일명규칙의 원칙에 따라 JSON `qnum` 기준으로 저장했다. PDF 인쇄번호와 다를 때도 앱·API가 참조하는 것은 JSON `qnum`이므로 `images/2016-1_q5.png`가 맞다.
- 계층 적합성: 오배치 없음.
  - "번호만으로 확정하지 말고 `stem`을 교차 확인한다"는 분야 원칙은 법률에 둔 것이 맞다.
  - "보정 매핑 단계를 절차에 추가한다"는 실행 순서이므로 시행령에 둔 것이 맞다.
  - "자료 필요 누락은 치명 오류"와 "보정 근거 미기록 감점"은 채점·판정 기준이므로 시행규칙에 둔 것이 맞다.
  - 실제 파일명·매핑·점검 명령은 설정값·실무 스니펫이므로 고시에 둔 것이 맞다.
- 충돌 여부: 없음.
  - 제4조의4는 즉시 실패가 아니라 "PDF 육안 대조 후보"를 출력하도록 설계되어, stem에 자료가 완전히 전사된 정상 문항을 무조건 실패로 만들지 않는다.
  - 00_README·문제추출 시행령·문제추출 고시의 참조를 모두 v1.2/v1.10으로 갱신해 참조무결성 위반이 없다.
- 이행확인심판:
  - 판례_012의 이행 추적 8개 항목이 모두 실제 문서와 데이터에 반영되어 있음을 확인했다.
  - JSON 파싱, 이미지 경로 존재, API 응답, 정적 파일 응답, 자료 필요 누락 후보 점검이 통과했다.
- 심판 점수: 합헌성 30 / 계층적합성 30 / 무충돌성 19 / 형식적합성 10 / 참조무결성 10 = 총 99점.

## 4. 주문

2016-1 Q5 이미지 보완, PDF 인쇄번호↔JSON qnum 보정 지침, 자료 필요 문항 누락 후보 자동점검 신설은 **합헌**이다.
