## 제2조 저장 규칙

- 이미지: `public/images/{examId}_q{qnum}.png` (경로 필드값은 `images/{examId}_q{qnum}.png`)
- 표: `<table>...</table>` HTML을 `table` 필드에.
- 삽입 대상 자료 유형: 그림·트리·그래프·제어흐름도·UML·구조도·네트워크도, 릴레이션·SQL 결과·스케줄링·세그먼트 테이블·진리표·상태표, 한 줄로 깨진 표.

## 제3조 자동 추출 스크립트

```text
scripts/extract_media.py  (2016~2023 처리)
scripts/extract_answers.py / extract_questions.py / extract_categories.py  (전체 재추출)
```

재추출 사전 요구: `pip install pdfplumber`

## 제4조 image / table 선택 기준 (요약)

```text
표가 깔끔하게 추출됨 → table
셀 병합·선·배치로 HTML이 깨짐 → image
그림·구조도 등 비표 자료 → image
```
