## 제1조 추출·대조 스크립트 목록

| 스크립트 | 용도 |
|---|---|
| `scripts/import_past_exam_pdfs.py` | 회차 PDF → `exam_*.json` 신규 생성 (2016~2023) |
| `scripts/extract_questions.py` | 2024·2025 회차 PDF에서 문제·보기·과목 추출 (2단 좌/우 분리) |
| `scripts/extract_answers.py` | 정답표 추출 (answer 확정용) |
| `scripts/extract_categories.py` | 유형별 PDF → `category_*.json` 추출 |
| `scripts/restore_text_from_pdfs.py` | 재추출: `stem`·`options`만 PDF 기준 복원, 나머지 필드 보존 |
| `compare_pdf_json.py` | PDF ↔ JSON 원문 대조 검수 |

사전 요구: `pip install pdfplumber`

## 제2조 실행 전 필수 확인 (경로 정정)

스크립트 상수 경로가 폐기된 환경을 가리키는 경우가 있다. **실행 전 반드시 정정한다.**

```text
폐기 경로 예: /Users/woonho/Downloads/... , /sessions/.../mnt/... (샌드박스)
정정 기준:   PDF  → 프로젝트 루트 `정보처리기사 문제/`
            JSON → 프로젝트 루트 `data/`
(경로 기준: 고시_추출삽입_PDF매핑_저장규칙 제1조, 결정례_2026헌가2)
```

## 제3조 변환·정규화 규칙

1. 원 숫자 매핑: `① → 1, ② → 2, ③ → 3, ④ → 4` (options 순서 = 원 숫자 순서, answer는 정수/배열).
2. 2단 편집 PDF는 단어의 x좌표로 좌/우 단을 분리하고 좌측 전체 → 우측 전체 순서로 읽는다.
3. `제N과목` 라벨로 과목 경계를 나눈다.
4. `subject`·`subjectName`은 해당 회차 PDF의 과목 라벨과 **기존 데이터의 부여 체계**를 따른다. 2016~2019 회차는 구 과목 체계를 현행 5과목에 매핑한 기존 값이 있으므로, 재추출 시 기존 `subject`·`subjectName`을 보존하고 임의 재배정하지 않는다.
5. 필드 구조·파일명은 고시_데이터_JSON스키마_파일명규칙, JSON↔PDF 매핑은 고시_추출삽입_PDF매핑_저장규칙 제1조를 준용한다 (이 고시에 중복 기재하지 않는다).

## 제4조 추출·검수 보고 양식

```text
[문제 추출 보고]
- 대상: exam_YYYY-N (모드: 신규 / 재추출)
- 문항 수: PDF n문항 / JSON n문항
- 치명 오류: 0건 (있으면 제1조 항목별 목록)
- 문제별 판정: 통과 n / 조건부 n / 재검수 n / 실패 n (평균 점수)
- 보존 확인(재추출): explanation·image·table·answer 변경 0건
- 저장 위치: 08_운영기록/리포트/
```

## 제5조 금지 설정

1. 문제·보기·정답을 모델 기억으로 재구성해 채우는 설정 금지 — 반드시 PDF 파싱 기반으로만 생성한다.
2. 정답을 외부 사이트·타 문제은행에서 가져오는 설정 금지 — 본인 보유 원본의 공식 정답만 쓴다.
3. 대조 검수 없이 추출 산출물을 `data/`에 바로 덮어쓰는 일괄 실행 금지.
