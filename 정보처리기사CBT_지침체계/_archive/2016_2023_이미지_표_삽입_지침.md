# 2016~2023 기출 이미지·표 삽입 지침

이 문서는 2016~2023 회차별 기출 JSON에 빠져 있는 그림·표 문제를 PDF 원본에서 찾아 `image` 또는 `table` 필드로 붙이는 기준이다. 기준은 이미 정상적으로 들어가 있는 2024·2025 회차와 유형별 문제의 방식에 맞춘다.

## 목표

2016~2023 기출 문제에서 다음에 해당하는 문제를 PDF에서 다시 확인해 앱 데이터에 보강한다.

- 그림, 트리, 그래프, 제어 흐름도, UML, 프로그램 구조도, 네트워크 구성도
- 릴레이션, SQL 결과, 스케줄링, 세그먼트 테이블, 진리표, 상태표
- PDF에서는 표/그림인데 현재 JSON `stem`에 한 줄 텍스트로 깨져 들어간 문제

## 현재 앱 데이터 형식

2024·2025 기출과 유형별 문제에서 쓰는 형식을 그대로 따른다.

```json
{
  "qnum": 23,
  "stem": "다음 트리의 차수(degree)는?",
  "options": ["2", "3", "4", "5"],
  "answer": 2,
  "explanation": "...",
  "image": "images/2024-1_q23.png"
}
```

표는 앱에서 이미 `table` 필드를 렌더링할 수 있으므로, 구조가 깔끔하게 추출되면 HTML 테이블을 넣는다.

```json
{
  "qnum": 51,
  "stem": "다음 릴레이션의 카디널리티와 차수가 옳게 나타낸 것은?",
  "table": "<table><tr><th>아이디</th><th>성명</th></tr><tr><td>yuyu01</td><td>원유철</td></tr></table>"
}
```

다만 PDF 표가 복잡하거나 `pdfplumber`가 셀을 깨뜨리면 `table`보다 표 영역을 이미지로 저장하는 편이 안전하다.

## 저장 규칙

이미지 파일은 모두 다음 위치에 저장한다.

```text
public/images/{examId}_q{qnum}.png
```

JSON에는 상대 경로만 넣는다.

```json
"image": "images/2019-2_q49.png"
```

`examId`는 현재 데이터 파일명과 맞춘다.

- `data/exam_2016-1.json` → `2016-1`
- `data/exam_2020-1-2.json` → `2020-1-2`
- `data/exam_2023-3.json` → `2023-3`

## PDF 위치

원본 PDF는 다음 폴더를 기준으로 한다.

```text
/Users/woonho/Downloads/정보처리기사 문제
```

기존 `scripts/import_past_exam_pdfs.py`의 `EXAMS` 목록과 파일명을 그대로 사용하면 된다.

## 삽입 판단 기준

### `image`로 넣을 것

아래 문제는 반드시 이미지로 저장한다.

- 트리, 그래프, DFS/BFS 그림
- UML 다이어그램, E-R 다이어그램
- 제어 흐름 그래프, McCabe 복잡도 그림
- Fan-In/Fan-Out 프로그램 구조도
- 네트워크 구성도, 방화벽 구성도, 토폴로지
- 표처럼 보이지만 셀 병합, 선, 배치 때문에 HTML 표로 깨지는 자료

2024·2025 예시:

- `exam_2024-1.json` Q23: 트리 차수 → `images/2024-1_q23.png`
- `exam_2024-3.json` Q39: DFS 그래프 → `images/2024-3_q39.png`
- `exam_2024-3.json` Q67: HRN 작업 표 → 이미지로 보존
- `exam_2025-3.json` Q26: 제어 흐름 그래프 → `images/2025-3_q26.png`
- `category_keyword.json` Q232: 네트워크 토폴로지 → `images/keyword_q232.png`

### `table`로 넣을 것

아래 조건을 모두 만족하면 `table` HTML로 넣는다.

- 행과 열이 명확하게 분리된다.
- 셀 병합이 없거나 없어도 의미가 유지된다.
- 보기와 문제 풀이에 필요한 값이 텍스트로 정확히 추출된다.

대표 대상:

- 릴레이션 카디널리티/차수 표
- SQL `UNION`, `JOIN`, `SELECT` 결과 비교 표
- 스케줄링 작업/대기시간/서비스시간 표
- 세그먼트 번호/기준주소/길이 표

단, 표 추출 결과가 깨지면 HTML로 억지 입력하지 말고 `image`로 넣는다.

## 문제 번호 매칭 기준

PDF는 보통 2단 편집이므로 이미지·표의 위치를 문제 번호에 붙일 때 아래 순서로 판단한다.

1. 같은 컬럼 안에서 이미지/표의 위쪽에 있는 가장 가까운 문제 번호를 찾는다.
2. 같은 컬럼에 문제 번호가 없으면 페이지 전체에서 위쪽에 있는 가장 가까운 문제 번호를 찾는다.
3. 이미지/표가 문제 번호 바로 아래가 아니라 보기 사이에 있어도, 문제 내용과 연결되는 번호에 붙인다.
4. 정답 페이지, 저작권 안내, 과목 제목, 페이지 머리말/꼬리말 이미지는 제외한다.

현재 `scripts/extract_media.py`의 `nearest_question_above()` 방식이 이 기준과 거의 같다.

## 추출 순서

1. PDF별로 이미지 후보와 표 후보를 먼저 탐지한다.
2. 후보 문제 번호를 JSON의 `qnum`과 매칭한다.
3. 이미지 후보는 해당 영역을 2.5배 이상 해상도로 잘라 `public/images`에 저장한다.
4. 표 후보는 `pdfplumber.find_tables()` 결과를 확인한다.
5. 표가 깨지지 않으면 `table` HTML을 넣고, 깨지면 해당 영역을 `image`로 넣는다.
6. 저장 후 앱에서 해당 문제를 열어 이미지/표가 정답 보기와 겹치지 않는지 확인한다.

## 자동 추출 스크립트 수정 방향

기존 `scripts/extract_media.py`는 2024·2025만 대상으로 되어 있으므로 다음처럼 바꾼다.

1. `PDF_MAP`에 2016~2023 PDF를 모두 추가한다.
2. PDF 경로 기준을 `/Users/woonho/Downloads/정보처리기사 문제`로 맞춘다.
3. 실행 대상 목록을 2016~2025 전체로 확장한다.
4. 이미지 저장명은 `{examId}_q{qnum}.png`로 통일한다.
5. 이미 `image`가 있는 문제는 덮어쓰지 않는다.
6. 이미 `table`이 있는 문제는 덮어쓰지 않는다.
7. 추출 후 후보 리포트를 남겨 사람이 검수할 수 있게 한다.

필수 검수 항목:

- 잘못된 문제 번호에 붙은 이미지가 없는가?
- 과목 제목, 광고, 저작권 안내, 페이지 번호가 이미지로 들어가지 않았는가?
- 표가 HTML로 들어갔을 때 셀 순서가 PDF와 같은가?
- 표가 깨졌으면 `table` 대신 `image`로 넣었는가?

## 표 처리 세부 기준

### HTML 표로 넣는 경우

HTML은 한 줄 문자열로 저장한다.

```html
<table><tr><th>작업</th><th>대기 시간</th><th>서비스 시간</th></tr><tr><td>A</td><td>5</td><td>20</td></tr></table>
```

문제 원문 `stem`에는 “다음 표를 보고” 같은 문장을 유지한다. 표 내용을 `stem`에 중복해서 길게 붙이지 않는다.

### 이미지로 넣는 경우

다음 중 하나라도 해당하면 이미지가 우선이다.

- 표 안에 선, 화살표, 괄호, 병합 셀이 있다.
- HTML로 바꾸면 보기와 대응되는 행/열 의미가 흐려진다.
- `pdfplumber` 추출 결과에서 셀 순서가 바뀐다.
- 표가 그림과 붙어 있다.

## 2024·2025 기준으로 본 좋은 삽입 예

좋은 삽입은 다음 조건을 만족한다.

- `stem`은 문제 문장만 담고, 그림 자체를 텍스트로 억지 복원하지 않는다.
- 그림은 문제 바로 아래에 표시되도록 `image` 필드에만 둔다.
- 풀이에 필요한 값은 `explanation`에 한 번 더 적는다.
- 같은 그림을 유형별 문제에서 재사용할 경우 기존 이미지 경로를 그대로 써도 된다.

예:

```json
{
  "qnum": 24,
  "stem": "다음 트리의 차수(degree)는?",
  "image": "images/2025-1_q24.png",
  "explanation": "주어진 트리에서 자식이 가장 많은 노드의 자식 수가 3이므로 트리의 차수는 3이다"
}
```

## 작업 완료 기준

2016~2023 전체에 대해 다음이 끝나면 완료로 본다.

1. 후보 문제의 PDF 원본 확인
2. `public/images`에 필요한 이미지 저장
3. `data/exam_*.json`에 `image` 또는 `table` 필드 추가
4. 앱에서 각 회차 문제 화면 렌더링 확인
5. 후보였지만 제외한 문제는 리포트에 이유 기록

권장 리포트 파일명:

```text
media_insert_report_2016_2023.txt
```

리포트에는 다음 형식으로 남긴다.

```text
2019-2 Q49: image 추가 images/2019-2_q49.png
2019-2 Q49: table 후보였지만 셀 병합으로 image 처리
2021-3 Q100: 이미지 후보였지만 페이지 장식이라 제외
```
