## 6. 검수 준비

### 6-1. 검수 대상 목록 추출

```bash
node - <<'NODE'
const fs = require('fs');
for (const file of fs.readdirSync('data').filter(f => /^exam_20(1[6-9]|2[0-3])/.test(f)).sort()) {
  const exam = JSON.parse(fs.readFileSync('data/' + file, 'utf8'));
  const img   = exam.questions.filter(q => q.image).map(q => `Q${q.qnum}(image)`);
  const table = exam.questions.filter(q => q.table).map(q => `Q${q.qnum}(table)`);
  const all   = [...img, ...table];
  if (all.length) console.log(`${file}: ${all.join(', ')}`);
}
NODE
```

### 6-2. 자동 유효성 점검

JSON 파싱 오류 확인:

```bash
node -e "const fs=require('fs'); for (const f of fs.readdirSync('data').filter(f=>/^exam_20(1[6-9]|2[0-3])/.test(f))) JSON.parse(fs.readFileSync('data/'+f,'utf8')); console.log('JSON OK')"
```

이미지 경로 실재 확인:

```bash
node - <<'NODE'
const fs = require('fs'), path = require('path');
let missing = [];
for (const file of fs.readdirSync('data').filter(f => /^exam_20(1[6-9]|2[0-3])/.test(f))) {
  const exam = JSON.parse(fs.readFileSync(path.join('data', file), 'utf8'));
  for (const q of exam.questions || [])
    if (q.image && !fs.existsSync(path.join('public', q.image)))
      missing.push(`${file} Q${q.qnum}: ${q.image}`);
}
missing.length ? (console.log(missing.join('\n')), process.exit(1)) : console.log('IMAGE PATH OK');
NODE
```

표 HTML 구조 확인:

```bash
node - <<'NODE'
const fs = require('fs');
let bad = [];
for (const file of fs.readdirSync('data').filter(f => /^exam_20(1[6-9]|2[0-3])/.test(f))) {
  const exam = JSON.parse(fs.readFileSync('data/' + file, 'utf8'));
  for (const q of exam.questions || []) {
    if (q.table) {
      const t = String(q.table);
      if (!/^<table>/.test(t))   bad.push(`${file} Q${q.qnum}: <table> 없음`);
      if (!/<\/table>$/.test(t)) bad.push(`${file} Q${q.qnum}: </table> 없음`);
      if (!/<tr>/.test(t))       bad.push(`${file} Q${q.qnum}: <tr> 없음`);
    }
  }
}
bad.length ? (console.log(bad.join('\n')), process.exit(1)) : console.log('TABLE HTML OK');
NODE
```

### 6-3. PDF 열기

- macOS 미리보기 또는 Adobe Acrobat으로 해당 회차 PDF를 연다.
- 2016~2019년 PDF는 과목별 페이지가 구분되므로 `⌘+F`로 문제 번호 주변 텍스트를 검색한다.
- 2020년 이후 PDF는 단일 파일에 1~100번 순서대로 수록되어 있다.

## 7. PDF 대조 실전 절차

### 7-1. PDF + PNG 나란히 보기 (macOS)

1. Finder에서 해당 PDF를 미리보기로 연다.
2. `public/images/`에서 해당 PNG 파일을 미리보기로 함께 연다.
3. 두 창을 Split View 또는 나란히 배치한다.
4. PDF에서 `⌘+F` → 문제 번호로 이동한다.
5. PNG와 PDF 그림을 육안으로 대조하며 위 채점표 항목을 체크한다.

### 7-2. 표 대조 절차

1. PDF를 확대해 헤더 행·데이터 행 수와 열 수를 센다.
2. JSON `table` HTML을 텍스트 에디터에서 열어 `<tr>` 수를 센다.
3. 행 단위로 위에서 아래로, 열 단위로 왼쪽에서 오른쪽으로 값을 대조한다.
4. 불일치 셀은 JSON을 직접 수정하고 감점 사유를 기록한다.

### 7-3. 클로드 코드 자동화 옵션

## 8. 오류 유형별 조치

| 오류 유형 | 확인 방법 | 조치 | 감점 |
|---|---|---|---:|
| 이미지가 다른 문제 그림 | `stem`과 PNG 불일치 | PDF bbox 재확인 후 재크롭 | 치명 |
| 이미지 일부 잘림 | PNG 가장자리 잘린 흔적 | 여백 추가 후 재저장 | -10~-25점 |
| 이미지 해상도 불량 | 픽셀 확대 시 뭉개짐 | DPI 150 이상으로 재추출 | -5~-15점 |
| 이미지에 불필요 영역 | 다른 번호·저작권 포함 | bbox 좁혀 재크롭 | -5~-15점 |
| 표 열 밀림 | PDF 헤더 수 ≠ `<th>` 수 | HTML 수정 또는 image 교체 | 치명 |
| 표 값 오탈자 | PDF 값과 불일치 | JSON table 필드 직접 수정 | -3~-5점/개 |
| 표 행 누락 | PDF 행 수 > `<tr>` 수 | 누락 행 추가 | -10~-20점 |
| JSON 경로 불일치 | `image` 경로 ≠ 실제 파일명 | 파일명 또는 경로 통일 | -7~-10점 |
