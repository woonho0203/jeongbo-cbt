# 이미지·표 삽입 점수제 검수 지침

이 문서는 2016~2023 기출에 추가한 이미지·표가 제대로 들어갔는지 점수로 검수하는 기준이다. 문제별 100점 만점으로 채점하고, 회차별 평균과 치명 오류 여부로 최종 통과를 판단한다.

## 최종 판정 기준

### 문제별 판정

| 점수 | 판정 | 처리 |
|---:|---|---|
| 95~100점 | 통과 | 수정 불필요 |
| 85~94점 | 조건부 통과 | 사소한 품질만 보정 |
| 70~84점 | 재검수 | PDF 원본과 다시 대조 |
| 0~69점 | 실패 | 이미지/표 재추출 또는 재삽입 |

### 회차별 판정

회차별 후보 문제 전체를 채점한 뒤 아래 기준을 적용한다.

| 기준 | 판정 |
|---|---|
| 평균 95점 이상, 실패 0개, 치명 오류 0개 | 통과 |
| 평균 90점 이상, 실패 0개, 치명 오류 0개 | 조건부 통과 |
| 평균 90점 미만 또는 실패 1개 이상 | 재작업 |
| 치명 오류 1개 이상 | 즉시 재작업 |

## 치명 오류

아래 항목은 점수와 관계없이 즉시 실패 처리한다.

- 다른 문제의 이미지나 표가 붙어 있다.
- 정답 페이지, 해설 페이지, 광고, 저작권 문구가 문제 자료로 들어갔다.
- 이미지 또는 표가 아예 표시되지 않는다.
- 문제 풀이에 필요한 핵심 값이 잘렸거나 누락됐다.
- 표의 행/열이 밀려 정답이 달라질 수 있다.
- JSON이 깨져 앱이 해당 회차를 불러오지 못한다.

## 문제별 100점 채점표

각 이미지·표 삽입 문제를 아래 기준으로 채점한다.

| 항목 | 배점 | 채점 기준 |
|---|---:|---|
| 문제 번호 매칭 | 25점 | PDF의 자료가 정확한 `qnum`에 붙었는가 |
| 자료 완전성 | 20점 | 그림/표의 필요한 영역이 빠짐없이 들어갔는가 |
| 가독성 | 15점 | 글자, 숫자, 선, 화살표가 충분히 읽히는가 |
| 불필요 영역 제거 | 10점 | 다른 문제, 페이지 번호, 저작권 문구가 섞이지 않았는가 |
| 앱 렌더링 | 15점 | 풀이/결과/오답/북마크 화면에서 정상 표시되는가 |
| 데이터 형식 | 10점 | `image` 경로 또는 `table` HTML 형식이 올바른가 |
| 해설 연계 | 5점 | 해설이 이미지/표의 핵심 값을 반영하는가 |
| 합계 | 100점 |  |

## 세부 채점 기준

### 1. 문제 번호 매칭: 25점

| 점수 | 기준 |
|---:|---|
| 25점 | PDF 원본의 그림/표가 정확한 문제 번호에 붙어 있다. |
| 20점 | 문제 번호는 맞지만 이미지 위치가 애매해 1회 추가 확인이 필요하다. |
| 10점 | 같은 페이지의 인접 문제와 헷갈릴 가능성이 있다. |
| 0점 | 다른 문제에 붙어 있다. 치명 오류다. |

### 2. 자료 완전성: 20점

| 점수 | 기준 |
|---:|---|
| 20점 | 문제 풀이에 필요한 그림/표 전체가 포함되어 있다. |
| 15점 | 불필요한 여백은 있지만 핵심 자료는 모두 포함되어 있다. |
| 8점 | 일부 선, 라벨, 헤더가 잘렸으나 정답 판단은 가능하다. |
| 0점 | 핵심 값이 잘려 정답 판단이 어렵다. 치명 오류다. |

### 3. 가독성: 15점

| 점수 | 기준 |
|---:|---|
| 15점 | 확대 없이 숫자·글자·선이 명확히 보인다. |
| 12점 | 약간 흐리지만 풀이에는 지장이 없다. |
| 6점 | 확대해야 겨우 읽힌다. |
| 0점 | 읽을 수 없다. 치명 오류다. |

### 4. 불필요 영역 제거: 10점

| 점수 | 기준 |
|---:|---|
| 10점 | 필요한 그림/표만 깔끔하게 들어갔다. |
| 7점 | 약간의 여백이나 주변 문장이 포함됐지만 방해되지 않는다. |
| 3점 | 다른 문제 일부가 보여 혼란을 줄 수 있다. |
| 0점 | 다른 문제, 정답표, 저작권 문구가 섞였다. 치명 오류다. |

### 5. 앱 렌더링: 15점

| 점수 | 기준 |
|---:|---|
| 15점 | 풀이 화면, 결과 화면, 오답 노트, 북마크 화면에서 모두 정상 표시된다. |
| 12점 | 풀이 화면은 정상이고, 부가 화면 중 하나에서만 경미한 표시 문제가 있다. |
| 6점 | 풀이 화면에서는 보이지만 크기나 배치가 불편하다. |
| 0점 | 앱에서 표시되지 않는다. 치명 오류다. |

### 6. 데이터 형식: 10점

| 점수 | 기준 |
|---:|---|
| 10점 | `image: "images/{examId}_q{qnum}.png"` 또는 정상 `<table>...</table>` 형식이다. |
| 7점 | 표시에는 문제 없지만 파일명/HTML이 권장 형식과 조금 다르다. |
| 3점 | 동작은 하지만 경로, 중복, HTML 구조가 불안정하다. |
| 0점 | JSON 파싱 오류, 누락 파일, 깨진 HTML이 있다. 치명 오류다. |

### 7. 해설 연계: 5점

| 점수 | 기준 |
|---:|---|
| 5점 | 해설에 그림/표에서 읽은 핵심 값이 들어 있다. |

## 자동 점검 명령

삽입된 이미지와 표 개수를 먼저 요약한다.

```bash
node - <<'NODE'
const fs = require('fs');
for (const file of fs.readdirSync('data').filter(f => /^exam_20(1[6-9]|2[0-3])/.test(f)).sort()) {
  const exam = JSON.parse(fs.readFileSync('data/' + file, 'utf8'));
  const img = exam.questions.filter(q => q.image).map(q => q.qnum);
  const table = exam.questions.filter(q => q.table).map(q => q.qnum);
  console.log(`${file}: image ${img.length} [${img.join(', ')}] / table ${table.length} [${table.join(', ')}]`);
}
NODE
```

이미지 파일 누락을 확인한다.

```bash
node - <<'NODE'
const fs = require('fs');
const path = require('path');
let missing = [];
for (const file of fs.readdirSync('data').filter(f => /^exam_20(1[6-9]|2[0-3])/.test(f))) {
  const exam = JSON.parse(fs.readFileSync(path.join('data', file), 'utf8'));
  for (const q of exam.questions || []) {
    if (q.image && !fs.existsSync(path.join('public', q.image))) {
      missing.push(`${file} Q${q.qnum}: ${q.image}`);
    }
  }
}
if (missing.length) {
  console.log(missing.join('\n'));
  process.exit(1);
}
console.log('IMAGE PATH OK');
NODE
```

표 HTML 형식을 확인한다.

```bash
node - <<'NODE'
const fs = require('fs');
let bad = [];
for (const file of fs.readdirSync('data').filter(f => /^exam_20(1[6-9]|2[0-3])/.test(f))) {
  const exam = JSON.parse(fs.readFileSync('data/' + file, 'utf8'));
  for (const q of exam.questions || []) {
    if (q.table && !/^<table>.*<\/table>$/.test(String(q.table))) {
      bad.push(`${file} Q${q.qnum}`);
    }
  }
}
if (bad.length) {
  console.log(bad.join('\n'));
  process.exit(1);
}
console.log('TABLE HTML OK');
NODE
```

## 검수 순서

1. 자동 점검 명령으로 JSON, 이미지 경로, 표 HTML을 확인한다.
2. 후보 목록과 실제 삽입 결과를 비교한다.
3. 각 문제를 PDF 원본과 대조해 문제별 100점 채점을 한다.
4. 앱에서 풀이 화면과 결과/복습 화면을 확인한다.
5. 점수 보고서를 작성한다.
6. 85점 미만 또는 치명 오류 문제는 재추출한다.
7. 회차 평균과 실패 개수로 최종 판정을 낸다.
