# 정보처리기사 CBT 문장·띄어쓰기 검수 지침

이 문서는 문제문, 보기, 해설에서 띄어쓰기·조사·문장 연결이 어색하게 붙은 부분을 검수하고 수정할 때 사용하는 기준이다. 목표는 원문 의미를 바꾸지 않고, 앱 화면에서 사람이 읽기 편한 문장으로 정리하는 것이다.

## 검수 대상

- 회차별 기출: `data/exam_*.json`
- 유형별 연습: `data/category_*.json`
- 필드: `questions[].stem`, `questions[].options[]`, `questions[].explanation`
- 우선순위: 화면에서 바로 보이는 `stem`과 `options`를 먼저 검수하고, 그다음 `explanation`을 검수한다.

## 핵심 원칙

1. 원문 의미, 정답 번호, 보기 순서는 바꾸지 않는다.
2. 붙어 있는 조사·어미·부사어만 자연스럽게 띄어 쓴다.
3. 전문 용어 내부 표기는 임의로 바꾸지 않는다.
4. 코드, SQL, 수식, 파일명, 명령어, 영문 식별자는 띄어쓰기 교정 대상에서 제외한다.
5. 문제에서 일부러 붙여 쓴 용어인지 판단이 애매하면 원문을 보존하고 검수 메모로 남긴다.

## 즉시 수정 대상

아래 유형은 발견 즉시 수정한다.

| 유형 | 나쁜 예 | 좋은 예 |
|---|---|---|
| 조사 붙음 | 정의에서부터시작하여 | 정의에서부터 시작하여 |
| 부사어 붙음 | 점차구체화하여 | 점차 구체화하여 |
| 명사구 붙음 | 범위정의 | 범위 정의 |
| 동사 연결 붙음 | 구현해간다 | 구현해 간다 |
| 괄호 뒤 조사 붙음 | 프로젝트(Project)의특징 | 프로젝트(Project)의 특징 |
| 문장 중복 공백 | 기능 추가  쉽다 | 기능 추가가 쉽다 |
| 어색한 OCR 띄어쓰기 | 이 러한 모듈 | 이러한 모듈 |

## 스크린샷 기준 예시

수정 전:

```text
모든 소프트웨어 프로젝트는 개략적인 범위 정의에서서부터 시 작하여 점차 구체화하여 구현해 간다.
```

수정 후:

```text
모든 소프트웨어 프로젝트는 개략적인 범위 정의에서부터 시작하여 점차 구체화하여 구현해 간다.
```

검수 포인트:

- `정의에서서부터`처럼 조사나 어미가 중복되면 원문/PDF 대조 후 자연스러운 형태로 고친다.
- `시 작하여`처럼 한 단어가 잘못 끊긴 경우 `시작하여`로 붙인다.
- `점차구체화하여`처럼 부사어와 동사가 붙은 경우 `점차 구체화하여`로 띄운다.
- `구현해간다`는 보조 용언 띄어쓰기 기준에 맞춰 `구현해 간다`를 권장한다.

## 자동 탐지 규칙

자동 검수 스크립트 또는 수동 검색 시 아래 패턴을 우선 찾는다.

```text
에서서부터
시 작
점차구체
구현해간다
의특징
에대한
가장거리
해당하지않
옳지않
틀린것
맞는것
이 러한
할수
될수
수있
```

단, `할 수`, `될 수`, `수 있다`는 교정 대상이지만 코드·SQL 문자열 안에서는 제외한다.

## 수동 검수 체크리스트

- [ ] 한글 단어가 중간에서 끊기지 않았는가
- [ ] 조사와 다음 단어가 붙어 있지 않은가
- [ ] 부사어와 동사가 붙어 있지 않은가
- [ ] 괄호 닫힘 뒤의 한글이 붙어 있지 않은가
- [ ] 불필요한 이중 공백이 없는가
- [ ] 코드, SQL, 수식, 영문 식별자의 공백은 건드리지 않았는가
- [ ] 수정 후 앱 화면에서 줄바꿈과 박스 표시가 자연스러운가

## 수정 금지 대상

아래는 띄어쓰기처럼 보여도 임의 수정하지 않는다.

- `SELECT A FROM R WHERE P` 같은 SQL
- `public static void main` 같은 코드
- `A→B`, `A₁`, `R₁`, `O(n)` 같은 수식·기호
- `Project`, `Walkthrough`, `Inspection` 같은 영문 용어
- 원문 자체가 시험 용어로 굳어진 표기

## 완료 기준

한 회차 또는 카테고리 검수 후 아래 조건을 만족해야 통과한다.

- JSON 파싱 오류가 없다.
- 앱에서 문제 화면이 정상 로딩된다.
- 검수 대상 문제의 질문·보기·해설에 눈에 띄는 붙임/끊김 오류가 없다.
- 수정 전후 의미가 같고 정답 판단에 영향을 주지 않는다.
