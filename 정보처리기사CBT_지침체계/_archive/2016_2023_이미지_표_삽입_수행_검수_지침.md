# 2016~2023 이미지·표 삽입 수행 및 검수 지침

이 문서는 `2016_2023_이미지_표_삽입_지침.md`에 따라 실제로 이미지·표를 삽입한 뒤, 누락·오매칭·렌더링 오류를 검수하는 절차이다.

## 작업 원칙

1. JSON의 `qnum`, `stem`, `options`, `answer`는 임의로 바꾸지 않는다.
2. 새로 추가하는 필드는 `image` 또는 `table`만 원칙으로 한다.
3. 자동 추출 결과는 반드시 PDF 원본과 앱 화면에서 검수한다.
4. 의심스러운 표는 `table` HTML보다 이미지 캡처를 우선한다.
5. 기존에 들어가 있던 `image` 또는 `table`은 검수 없이 덮어쓰지 않는다.

## 3단계: JSON 구조 검수

자동 삽입 후 JSON 파싱 오류가 없는지 확인한다.

```bash
node -e "const fs=require('fs'); for (const f of fs.readdirSync('data').filter(f=>/^exam_20(1[6-9]|2[0-3])/.test(f))) JSON.parse(fs.readFileSync('data/'+f,'utf8')); console.log('JSON OK')"
```

이미지 경로가 실제 파일로 존재하는지 확인한다.

```bash
node - <<'NODE'
const fs = require('fs');
const path = require('path');
let missing = [];
for (const file of fs.readdirSync('data').filter(f => /^exam_20(1[6-9]|2[0-3])/.test(f))) {
  const exam = JSON.parse(fs.readFileSync(path.join('data', file), 'utf8'));
  for (const q of exam.questions || []) {
    if (q.image && !fs.existsSync(path.join('public', q.image))) {
      missing.push(`${file} Q${q.qnum}: ${q.image}`);
    }
  }
}
if (missing.length) {
  console.log(missing.join('\n'));
  process.exit(1);
}
console.log('IMAGE PATH OK');
NODE
```

`table` 필드가 기본 HTML 형태를 갖췄는지 확인한다.

```bash
node - <<'NODE'
const fs = require('fs');
let bad = [];
for (const file of fs.readdirSync('data').filter(f => /^exam_20(1[6-9]|2[0-3])/.test(f))) {
  const exam = JSON.parse(fs.readFileSync('data/' + file, 'utf8'));
  for (const q of exam.questions || []) {
    if (q.table && !/^<table>.*<\/table>$/.test(String(q.table))) {
      bad.push(`${file} Q${q.qnum}`);
    }
  }
}
if (bad.length) {
  console.log(bad.join('\n'));
  process.exit(1);
}
console.log('TABLE HTML OK');
NODE
```

## 4단계: 후보 목록 대비 누락 검수

`2016_2023_이미지_표_삽입_지침.md`의 1차 후보 목록과 실제 삽입 결과를 비교한다.

검수 기준:

- 후보였는데 실제 삽입하지 않은 문제는 이유가 있어야 한다.
- 이미지 후보가 표로 처리되었거나 표 후보가 이미지로 처리된 경우도 이유를 기록한다.
- PDF 장식, 과목 제목, 페이지 번호, 정답표 등으로 판단해 제외한 경우 리포트에 남긴다.

리포트 예:

```text
2020-3 Q42: table 추가
2020-3 Q49: image 추가 images/2020-3_q49.png
2021-3 Q100: 이미지 후보였지만 페이지 장식이라 제외
2023-2 Q67: table 후보였지만 셀 병합이 깨져 image로 처리
```

## 5단계: PDF 원본 대조 검수

각 후보 문제를 PDF 원본과 대조한다.

확인할 항목:

- 이미지/표가 올바른 문제 번호에 붙었는가?
- 이미지가 문제에 필요한 영역만 포함하는가?
- 잘린 글자, 잘린 선, 잘린 보기 번호가 없는가?
- 이미지에 불필요한 다른 문제, 페이지 번호, 저작권 문구가 포함되지 않았는가?
- 표의 행/열 순서가 PDF 원본과 같은가?
- 표의 숫자, 한글, 영문 대소문자가 원본과 같은가?

문제 번호 매칭이 애매하면 자동 결과를 믿지 말고 PDF에서 직접 확인한다.

## 6단계: 앱 화면 검수

서버를 실행한다.

```bash
npm start
```

브라우저에서 다음 흐름으로 확인한다.

```text
회차별 기출문제 풀이 → 해당 연도/회차 선택 → 후보 문제 번호로 이동
```

앱 화면에서 확인할 항목:

- 이미지가 문제 문장 아래에 표시되는가?
- 표가 보기 위 또는 문제 문장 아래에 자연스럽게 표시되는가?
- 이미지/표가 너무 작거나 흐리지 않은가?
- 모바일 폭에서도 보기와 겹치지 않는가?
- 결과 화면, 오답 노트, 북마크 화면에서도 이미지/표가 보이는가?

앱은 `public/js/exam.js`, `public/js/views.js`에서 `image`와 `table`을 렌더링하므로, 풀이 화면뿐 아니라 결과/복습 화면도 같이 확인한다.

## 7단계: 표 검수 기준

`table` HTML은 다음 조건을 만족해야 통과다.

- 첫 행이 헤더이면 `<th>`를 사용한다.
- 데이터 행은 `<td>`를 사용한다.
- 빈 셀이 의미 있는 경우 빈 문자열로 남겨도 되지만, 행/열 수는 유지한다.
- 문제 풀이에 필요한 모든 값이 들어 있다.
- 원문에 있던 표를 `stem`에도 중복해서 길게 남기지 않는다.

아래 경우는 실패로 보고 이미지로 다시 처리한다.

- 열이 밀려서 값이 다른 헤더 아래에 들어간 경우
- 병합 셀 때문에 의미가 사라진 경우
- 수식, 화살표, 괄호, 선 구조가 중요한 경우
- 표 안의 줄바꿈이 사라져 보기가 헷갈리는 경우

## 8단계: 이미지 검수 기준

이미지는 다음 조건을 만족해야 통과다.

- 파일 경로: `public/images/{examId}_q{qnum}.png`
- JSON 경로: `images/{examId}_q{qnum}.png`
- 문제 해결에 필요한 그림 전체가 포함되어 있다.
- 해상도가 충분해 확대하지 않아도 읽을 수 있다.
- 주변 문제나 정답표가 섞이지 않았다.
- 같은 이미지가 중복 생성된 경우 재사용 가능한지 확인한다.

이미지가 너무 넓거나 불필요한 영역이 많으면 PDF bbox에 여백을 줄여 다시 저장한다. 글자가 잘렸으면 여백을 늘려 다시 저장한다.

## 9단계: 해설 보정 검수

이미지·표를 추가한 문제는 해설도 같이 확인한다.

반드시 해설에 들어가야 하는 정보:

- 트리: 차수, 단말 노드 수, 순회 결과
- 그래프: 탐색 시작점, 방문 순서
- 제어 흐름도: 간선 수, 노드 수 또는 폐쇄 영역 수
- 릴레이션: 행 수, 열 수
- 스케줄링: 공식, 각 작업 계산값, 정렬 순서
- 세그먼트: 기준 주소, 길이, 변위, 최종 물리 주소
- SQL 표: 중복 포함/제거 여부, 최종 결과 행

이미지·표만 넣고 해설이 “그림 기준 정답”처럼 막연하면 보정 대상이다.

## 10단계: 최종 자동 점검

최종적으로 삽입 개수를 요약한다.

```bash
node - <<'NODE'
const fs = require('fs');
for (const file of fs.readdirSync('data').filter(f => /^exam_20(1[6-9]|2[0-3])/.test(f)).sort()) {
  const exam = JSON.parse(fs.readFileSync('data/' + file, 'utf8'));
  const img = exam.questions.filter(q => q.image).map(q => q.qnum);
  const table = exam.questions.filter(q => q.table).map(q => q.qnum);
  console.log(`${file}: image ${img.length} [${img.join(', ')}] / table ${table.length} [${table.join(', ')}]`);
}
NODE
```


## 최종 완료 조건

아래 조건을 모두 만족하면 완료 처리한다.

- 2016~2023 후보 문제의 삽입/제외 사유가 모두 리포트에 있다.
- 모든 `image` 경로가 실제 파일을 가리킨다.
- 모든 `table` 필드가 앱에서 깨지지 않는다.
- PDF 원본과 문제 번호 매칭이 맞다.
- 앱 풀이 화면과 결과/복습 화면에서 이미지·표가 정상 표시된다.
- JSON 파싱 오류가 없다.
- 기존 2024·2025 및 유형별 이미지 경로가 깨지지 않았다.
