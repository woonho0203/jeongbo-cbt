## 1. 원인 분석

Q5 JSON 문항에는 `image` 필드가 없었지만, 원본 PDF에는 트리 그림이 존재했다. PDF에서 해당 문항은 1쪽 오른쪽 컬럼의 인쇄번호 `10.`으로 표시되어 있었고, 앱 JSON에서는 Q5로 저장되어 있었다.

근본 원인은 다음 2개다.

1. 기존 자동 이미지 추출은 PDF 인쇄 번호와 JSON `qnum`이 같다고 가정했다.
2. 기존 자동점검은 `image` 필드가 있는 경우의 파일 존재 여부만 확인했고, "다음 트리/그림/표"처럼 자료가 필요한데 `image`·`table` 필드 자체가 없는 문항을 잡지 못했다.
