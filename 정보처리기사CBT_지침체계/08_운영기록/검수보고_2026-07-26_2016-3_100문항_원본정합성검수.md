# 검수보고_2026-07-26_2016-3_100문항_원본정합성검수

## 1. 검수 목적

2단계 원본 데이터 정합성 확보의 세 번째 파일 단위 작업으로 `data/exam_2016-3.json` 100문항을 보유 PDF와 전수 대조했다.

기존 `pdf_compare_score_report.txt`에는 `exam_2016-3`의 이미지·표 점수가 92.4점으로 기록되어 있었고, Q58 메모리 블록 표의 정확한 크기 값을 PDF 원본으로 다시 확인하라는 잔여 권고가 있었다. 이번 검수는 해당 권고를 해소하고, 공식 정답표와 원문·보기·자료 연결을 함께 확인하기 위해 수행했다.

이번 보고서는 `exam_2016-3.json` 한 파일의 검수 완료를 뜻하며, 전체 3,568문항의 2단계 완료를 뜻하지 않는다.

- 직접 원본: `정보처리기사 문제/2016년3회_정보처리기사_필기_기출문제.pdf`

PDF는 A형이고 JSON `qnum`과 PDF 인쇄번호가 1~100으로 일치한다. PDF 1~7쪽을 220DPI PNG로 렌더하고, Apple Vision OCR과 `pdftotext -layout` 결과를 보조 자료로 사용했다. 최종 판단은 렌더 이미지의 문제 본문·보기·공식 정답표·그림·표를 직접 확인해 내렸다.

## 3. 발견된 오류

### 3.1 공식 복수정답 누락

PDF 정답표는 Q21에 `②, ④`를 함께 표시한다. 기존 JSON은 `answer: 2` 하나만 저장하고 있었다.

- 변경 전: `answer: 2`
- 변경 후: `answer: [2, 4]`
- 해설: D 플립플롭과 T 플립플롭의 동작 차이를 반영해 2번과 4번이 모두 틀린 설명임을 설명

공식 정답표 100개와 JSON 정답을 대조한 결과, 이 1건을 고친 뒤 100/100이 일치했다.

### 3.2 Q58 메모리 블록 표 오류

Q58은 15M 블록을 어느 빈 영역에 할당하는지로 메모리 배치 정책을 판별하는 문제다. PDF 그림의 빈 영역은 다음과 같다.

| 영역 | 크기 | 상태 |
|---|---:|---|
| ⓐ | 6M | 빈영역 |
| ⓑ | 20M | 빈영역 |
| ⓒ | 16M | 빈영역 |
| ⓓ | 24M | 빈영역 |
| ⓔ | 22M | 빈영역 |

기존 JSON 표는 ⓐ~ⓔ를 `사용 중`으로 표시하고, 크기 값도 빠져 있었다. PDF 원본에 따라 크기와 상태를 복원했다.

- 정답: Best-Fit
- 근거: 15M 이상인 빈 영역 중 가장 작은 영역이 16M인 ⓒ
- First-Fit이면 20M인 ⓑ, Worst-Fit이면 24M인 ⓓ가 선택됨

### 3.3 해설 내부 작업 메모 잔존

Q15 해설에 영어 작업 메모 문장 `Wait - ...`가 남아 있었다. PDF 원문과 수식 트리 순회 결과를 기준으로 전위 순회 과정을 다시 작성했다.

### 3.4 원문·보기 전사 차이

총 52문항의 147개 필드를 PDF 원본과 맞췄다.

| 필드 | 변경 문항 수 | 대표 사례 |
|---|---:|---|
| `stem` | 32 | Q10 `Selection Sort`, Q15 `Preorder-Traversal`, Q22 `Hamming Code`, Q44 물음표 2개, Q56 `디렉터리`, Q91 `8KHz` |
| `options` | 30 | Q1 `개체 무결 제약 조건`, Q6 `∪`, Q15 전위 표기 공백, Q32 `4×4 디코더`, Q66 `이미 있는 훈련` |
| `answer` | 1 | Q21 `2 → [2,4]` |
| `table` | 1 | Q58 빈 영역 크기·상태 표 복원 |
| `explanation` | 9 | Q1·Q6·Q15·Q21·Q56·Q58·Q59·Q66·Q71 |

문제 의미를 바꾸지 않는 임의 각색은 하지 않았고, PDF에서 확인한 원문·보기·정답과 그에 직접 연결되는 해설만 수정했다.
