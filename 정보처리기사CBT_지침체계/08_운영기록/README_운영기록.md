# 08_운영기록 안내

이 폴더는 실행 로그·결과·변경 이력을 보관한다. **규칙이 아니라 근거**로만 쓴다. (마스터프레임워크 4.2)

## 구성

- `changelog.md` — 지침체계 전체 변경 이력 (필수 갱신)
- `시행보고/` — 회차·유형별 지침 시행 보고 22건 (기존 CBT 작업 기록)
- `리포트/` — 자동 점검·추출·대조 산출물 15건 (검수·추출 로그)

## 사용 규칙

1. 지침을 만들거나 수정하면 반드시 `changelog.md`에 한 줄 남긴다.
2. 시행보고·리포트는 참고 근거로만 인용하고, 여기서 규칙을 새로 만들지 않는다.
3. 같은 문제가 반복 확인되면 06_판례로 승격 후보로 올린다.
4. 새 검수·삽입 보고는 05_고시의 보고 양식을 따라 이 폴더에 저장한다.
