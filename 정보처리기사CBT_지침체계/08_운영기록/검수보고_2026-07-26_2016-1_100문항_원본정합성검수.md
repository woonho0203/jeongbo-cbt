# 검수보고_2026-07-26_2016-1_100문항_원본정합성검수

## 1. 검수 목적

2단계 원본 데이터 정합성 확보의 두 번째 파일 단위 작업으로 `data/exam_2016-1.json` 100문항을 보유 PDF와 전수 대조했다.

기존 `pdf_compare_score_report.txt`에서 이 회차의 이미지·표 최종 점수는 86.0점으로 2016~2017년 6회차 중 가장 낮았다. 또한 PDF 인쇄번호와 JSON `qnum`이 다르다는 기존 판례가 있어 다음 고위험 단위로 선정했다.

이번 보고서는 `exam_2016-1.json` 한 파일의 검수 완료를 뜻하며, 전체 3,568문항의 2단계 완료를 뜻하지 않는다.

## 2. 직접 원본과 검수 방법

- 직접 원본: `정보처리기사 문제/2016년1회_정보처리기사_필기_기출문제.pdf`
- 데이터: `data/exam_2016-1.json`
- 자료: `public/images/2016-1_q*.png`

PDF는 B형이고 JSON은 다른 문제 순서를 사용하므로 같은 번호끼리 비교하지 않았다. 1~7쪽을 200DPI로 렌더하고 Apple Vision OCR 결과와 PDF 텍스트를 보조 자료로 사용한 뒤, `stem` 핵심 문구로 100문항을 일대일 대응시켰다. 원문·보기·공식 정답표·그림·표는 렌더한 PDF 1~8쪽을 직접 확인했다.

## 3. PDF 인쇄번호와 JSON qnum 대응

문장 기반 대응은 100/100 성공했고 PDF 문제번호도 1~100이 한 번씩만 사용됐다.

```text

JSON 21~40 → PDF 37,35,40,39,31,22,26,21,29,33,25,23,34,32,38,30,36,24,28,27
JSON 41~60 → PDF 45,43,55,57,42,56,53,47,52,54,51,49,44,58,41,60,59,50,48,46
JSON 61~80 → PDF 62,74,73,72,64,67,70,66,76,63,80,69,71,75,68,65,61,78,77,79
JSON 81~100 → PDF 81,98,93,87,83,82,90,96,95,88,84,89,100,94,91,92,99,85,97,86
```

따라서 예를 들어 JSON Q71의 직접 원본은 PDF 인쇄번호 Q80이고, JSON Q91의 직접 원본은 PDF 인쇄번호 Q84다.

## 4. 발견된 오류

### 4.1 공식 복수정답 누락

PDF 정답표는 인쇄번호 Q80에 `②·④`를 함께 표시한다. 이 문항은 JSON Q71에 대응하지만 기존 `answer`는 `2` 하나뿐이었다.

- 변경 전: `answer: 2`
- 변경 후: `answer: [2, 4]`
- 해설: Spiral Model과 Prototype Model이 각각 인정되는 근거와 단일정답 유사 문제 구별법을 반영

문장 대응 후 공식 정답표를 적용한 결과, 이 1건을 고친 뒤 100/100이 일치했다.

### 4.2 풀이 필수 표 누락

JSON Q45는 PDF 인쇄번호 Q42의 First-Fit 문제다. 기존 JSON에는 `영역 1~4` 보기만 있고 문제 풀이에 필요한 영역 크기 `9K·15K·10K·30K`가 없었다.

- HTML `table` 필드로 네 영역의 크기를 복원
- 해설에 각 영역 값과 영역 2를 처음 선택하는 과정을 반영

### 4.3 잘린 HDLC 보기

JSON Q91의 기존 이미지에는 PDF 인쇄번호 Q84의 보기 ①~③만 있었고, 다음 열에 이어진 보기 ④가 잘려 있었다.

- `public/images/2016-1_q91.png`를 원본 PDF에서 다시 추출
- 보기 ①~④를 한 이미지에 순서대로 배치
- JSON 번호와 혼동되는 PDF 인쇄번호 `84.`와 인접 Q85는 제외

### 4.4 원문·보기 전사 오류

총 53문항의 77개 필드를 원본과 맞췄다.

| 필드 | 변경 문항 수 | 대표 사례 |
|---|---:|---|
| `stem` | 42 | Q23 `갈이→길이`, Q28 `PLA→PIA`, Q53 `프로세서→프로세스`, Q71 `부석→분석`, Q74 `동적→동작`, Q79 `요민→요인`, Q80 `요구상항→요구사항`, Q89 `FIS→FCS` |
| `options` | 27 | Q28 `PLA/PAL`, `LPGA/FPGA`; Q59 `INODE LIST→INODE BLOCK`; 중복 글자·띄어쓰기·대소문자 복원 |
| `answer` | 1 | Q71 `2→[2,4]` |
| `table` | 1 | Q45 영역 크기 표 추가 |
| `explanation` | 6 | Q43·45·55·59·71·84의 원문·정답·용어 변경 연동 |

설명 내용을 새 문제로 각색하지 않았고, PDF에서 확인된 원문·보기·정답과 그에 직접 연결되는 해설만 수정했다.
