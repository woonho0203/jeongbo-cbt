# 검수보고_2026-07-26_2018-1_100문항_원문보기자동대조

## 1. 검수 범위

- 원본 PDF: `정보처리기사 문제/2018년1회_기사필기_기출문제.pdf`
- 대상 데이터: `data/exam_2018-1.json`
- 검수 대상: Q1~Q100의 `stem`, `options`, `answer`, 표·이미지 연결
- 배포 여부: 이번 보고 단위에서는 배포하지 않음

## 2. 검수 방법

1. PDF 1~6쪽을 `pdfplumber`로 좌·우 칼럼 분리 추출했다.
2. 추출된 텍스트를 Q1~Q100 블록으로 재구성했다.
3. 각 JSON 문항의 `stem`과 4개 `options`가 자기 PDF 문항 블록에 포함되는지 자동 비교했다.
4. 자동 후보는 PDF 렌더 이미지로 육안 확인한 뒤 확정 오류만 수정했다.
5. PDF 7쪽 정답표 전사값과 JSON 정답을 다시 비교했다.
