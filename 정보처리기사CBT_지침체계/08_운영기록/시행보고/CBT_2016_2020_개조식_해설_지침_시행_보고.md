## 4. 2018년 2회 검사 기법 문제 전후 비교

- 문항: 다음 검사의 기법 중 종류가 다른 하나는 무엇인가?
- 회차: 2018년 2회
- 정답 보기: 데이터 흐름 검사

### 수정 전

데이터 흐름 검사는 이 범주에 해당하지 않는다. 이 범주에는 동치 분할 검사·원인 효과 그래프 검사·비교 검사 등이 포함된다.

### 수정 후

- 정답 분석: '데이터 흐름 검사'는 문제 요구에서 찾는 틀린 설명 또는 종류가 다른 보기임. 데이터 흐름 검사는 프로그램 내부 변수의 정의·사용 흐름을 확인하는 화이트박스 검사 기법임. 동치 분할 검사, 원인 효과 그래프 검사, 비교 검사는 입력·출력 관점에서 검사하는 블랙박스 계열 기법이므로 분류가 다름.
- 개념 정의: 데이터 흐름 검사는 프로그램 내부의 변수 정의와 사용 흐름을 추적하는 화이트박스 검사 기법임
- 오답 분석: 1번 동치 분할 검사, 2번 원인 효과 그래프 검사, 3번 비교 검사 등은 문제에서 묻는 범주에 속하거나 올바른 설명에 해당하므로 정답 조건에서 제외됨.
- 주의(함정): 같은 용어처럼 보여도 블랙박스/화이트박스, 구조/행위, 관리/개발처럼 분류 기준을 먼저 잡아야 함.
