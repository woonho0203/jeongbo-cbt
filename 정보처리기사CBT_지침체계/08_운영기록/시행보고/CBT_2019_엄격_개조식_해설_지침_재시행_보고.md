### 2019년 2회 Q1

```text
- 정답 분석: '입력 제한 데크는 Shelf이고, 출력 제한 데크는 Scroll이다.'는 입력 제한 데크와 출력 제한 데크의 명칭을 서로 뒤바꾼 설명임. 일반적으로 입력 제한 데크는 Scroll, 출력 제한 데크는 Shelf로 구분하므로 이 보기는 데크의 제한 방식 설명이 틀림.
- 개념 정의: 데크(Deque)는 Double Ended Queue의 약자로, 리스트의 양쪽 끝에서 삽입과 삭제를 수행할 수 있는 선형 자료구조임. 입력 제한 데크는 입력 위치를 한쪽으로 제한하고, 출력 제한 데크는 출력 위치를 한쪽으로 제한함.
- 오답 분석:
  - 2번 삽입과 삭제가 리스트의 양쪽 끝에서 발생할 수 있는 자료 구조이다.: 데크의 기본 정의를 설명한 올바른 문장임.
  - 3번 스택과 큐의 장점으로 구성한 것이다.: 데크는 한쪽 끝만 사용하는 스택과 한쪽 입력·한쪽 출력 구조인 큐보다 양끝 연산이 자유로워 두 구조의 성질을 함께 활용할 수 있음.
  - 4번 Double Ended Queue의 약자이다.: Deque의 영문 풀이는 Double Ended Queue이므로 올바른 설명임.
- 주의(함정): 데크 문제에서는 양쪽 끝 연산이 가능하다는 기본 정의와 입력 제한·출력 제한 변형의 명칭을 구분해야 함.
```
