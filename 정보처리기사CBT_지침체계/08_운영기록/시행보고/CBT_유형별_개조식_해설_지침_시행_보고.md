# CBT 유형별 개조식 해설 지침 시행 보고

- 시행일: 2026-05-21
- 적용 지침: `CBT_해설_정의_오답비교_작성_지침.md`
- 적용 범위: 유형별 문제 5개 카테고리

## 1. 적용 기준

- 긍정형 문제는 `개념 정의 -> 정답 분석 -> 오답 분석 -> 주의(함정)` 흐름으로 정리함.
- 부정형 문제는 정답 보기가 왜 틀린 설명 또는 종류가 다른 보기인지 먼저 밝히고, 나머지 보기가 왜 정답 조건에서 제외되는지 비교함.
- 계산·코드 유형은 `핵심 개념 -> 도출 과정 -> 최종 결과 -> 오답 분석 -> 주의(함정)` 흐름으로 정리함.
- 단순히 `정답은 N번이다`, `해당하지 않는다`로 끝나는 해설이 남지 않도록 정리함.

## 4. 샘플 확인

대상 문항:

- 유형: 코드
- 문항: 다음 C언어 프로그램이 실행되었을 때, 실행 결과는?

적용 해설:

- 핵심 개념: C언어 실행 결과 문제는 배열, 포인터, 문자열, 연산 순서를 차례로 추적해 출력값을 구하는 문제임
- 도출 과정: 문제의 조건, 코드 실행 흐름, 계산식 또는 알고리즘 적용 순서를 차례로 추적함. 보기 중 'R'가 조건을 만족함.
- 최종 결과: 'R'가 최종 출력값 또는 계산 결과에 해당하므로 정답임.
- 오답 분석: 1번 E, 2번 V, 4번 O 등은 계산식 적용, 실행 순서, 조건 판단, 인덱스 해석 중 하나를 다르게 적용한 결과임.
- 주의(함정): 계산식 적용 순서, 조건 판단 시점, 반복 종료 조건, 배열 인덱스, 연산자 우선순위를 단계별로 확인해야 함.
