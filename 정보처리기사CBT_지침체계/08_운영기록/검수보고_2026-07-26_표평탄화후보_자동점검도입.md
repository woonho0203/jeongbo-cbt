# 검수보고_2026-07-26_표평탄화후보_자동점검도입

## 1. 검수 목적

사용자 질의: "표인데 그게 표로 없고 그냥 글로만 문제에 들어가있는것도 잡아내나?"

이에 따라 PDF 원본에는 행·열 구조 또는 구조화 자료가 있는데 JSON에는 `stem`·`options` 줄글로만 들어간 문항을 자동 후보화하는 점검을 추가하고, 실제 데이터 전체에 1차 실행했다.

## 2. 추가한 점검

- 실행 명령: `node scripts/audit_plaintext_table_candidates.js`
- 엄격 모드: `node scripts/audit_plaintext_table_candidates.js --fail-on-candidates`
- 정상 예외 확인: `node scripts/audit_plaintext_table_candidates.js --show-known`

판정 원칙:

1. 자동 결과는 오류 확정이 아니라 PDF 대조 후보로 본다.
2. 원본 PDF의 행·열 구조가 정답 판단에 필요하면 `table` 또는 `image`로 복원한다.
3. 표가 아니라 코드·명령어 목록·보기 나열이면 정상 예외로 기록한다.
4. 구조화 목록이 줄글로 무너졌으면 `stem` 줄바꿈 또는 해설을 복원한다.

## 3. 실행 결과

최종 실행:

```text
node scripts/audit_plaintext_table_candidates.js
PDF 표-텍스트 평탄화 후보 없음
```

정상 예외 조회:

```text
node scripts/audit_plaintext_table_candidates.js --show-known
확인 완료 정상 예외 4건
```

무결성 확인:

## 6. 남은 한계

- 이 점검은 JSON 내부의 줄바꿈·값 나열·표 단서를 보는 휴리스틱이다.
- PDF에 표가 있는데 JSON에 표 단서도 값 나열도 남지 않은 "완전 누락"은 여전히 회차별 PDF 1:1 대조로 확인해야 한다.
- 따라서 이 점검은 2단계 원본 데이터 정합성 검수의 보조 장치이며, PDF 대조를 대체하지 않는다.

## 7. 결론

현재 저장소 전체 기준 미확인 PDF 표-텍스트 평탄화 후보는 0건이다. 확인 완료 정상 예외 4건은 스크립트 allowlist에 기록했으며, 실제 구조 손실이 확인된 2017-2 Q26과 OCR 첨자 손상이 확인된 2017-3 Q28은 원본 PDF 대조 근거로 수정했다.
