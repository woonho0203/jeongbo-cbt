## 제1조 목적

이 법은 완성된 데이터(해설·이미지·표·문장)가 배포 가능한 품질인지 대조·채점·판정하는 기본 규칙을 정한다.

## 제2조 정의

1. **해설 검수**: `explanation`이 정답을 정확·충분히 설명하는지 판정.
2. **이미지·표 검수**: 삽입된 `image`·`table`이 PDF 원본과 일치하는지 판정.
3. **PDF 대조 검수**: JSON 자료와 PDF 원본을 1:1로 대조해 채점.
4. **문장·띄어쓰기 검수**: 원문 의미를 바꾸지 않고 읽기 편한 문장으로 정리.
5. **치명 오류**: 점수와 무관하게 즉시 실패로 처리하는 오류.

## 제3조 기본 원칙

1. 검수는 실제로 읽고 대조한 것만 근거로 한다. (헌법 제7조, 라우터 읽기 원칙)
2. 정답 정확성이 의심되면 해설만 고치지 말고 원문/PDF/신뢰 교재와 대조한다.
3. 원문·보기에 OCR 오류가 있어도 검수 중에는 별도 메모로 남기고 임의 수정하지 않는다. (데이터관리법 제5조)
4. 대량 수정 뒤에는 반드시 JSON 파싱 점검과 앱 실행 확인을 한다.
5. 자동 스크립트가 만든 해설은 초안으로 보고, 부정형·코드·계산·그림 문제를 우선 수동 검수한다.

## 제4조 허용

1. 문제별 채점 후 판정(통과/보완/재검수/실패 또는 통과/조건부통과/재검수/실패) 부여.
2. 원문 의미 보존 범위의 띄어쓰기·조사·문장 연결 교정.
3. 자동 점검 명령으로 후보 목록화 (하급 모델 위임 가능).

## 제5조 금지

1. 읽지 않은 문서·대조하지 않은 자료를 근거로 판정.
2. 치명 오류를 점수로 상쇄해 통과 처리.
3. 전문 용어 내부 표기·코드·수식·영문 식별자를 띄어쓰기 교정 대상으로 삼기.
4. 검수 결과 없이 배포본 확정. (헌법 제6조)

## 제6조 품질 기준

- 검수 대상별 통과선(04_시행규칙)을 충족해야 배포 가능하다.
- 회차·유형 단위 판정에서 실패 0개가 원칙이며, 재검수 잔존 시 보고서에 사유를 남긴다.
- 자동 점검 명령·수동 보고 양식·우선 검수 순서는 05_고시에 위임한다.

## 제7조 다른 법률과의 관계

1. 검수 대상 필드·무결성 판정은 데이터관리법을 전제로 한다.
2. 해설 검수는 해설작성법의 작성 기준을, 이미지·표 검수는 추출·삽입법의 삽입 기준을 판정 잣대로 쓴다.
3. 검수에서 반복 확인된 오류 유형은 판례로 축적하고, 3회 이상 반복되면 승격심판으로 시행규칙·법률에 반영한다. (헌법재판소법 제12조)
