# 06_판례 안내

이 폴더는 실제 작업에서 나온 성공·실패·개선 사례와 그 교훈을 보관한다. 일반 규칙은 여기 두지 않고, 반복되면 시행규칙·법률로 승격한다. (마스터프레임워크 4.2, 헌법재판소법 제12조)

## 폴더

- `성공사례/` — 앞으로 반복할 좋은 패턴
- `실패사례/` — 재발 방지가 필요한 오류 패턴
- `개선사례/` — 수정 전후 비교로 배우는 사례

## 판례 파일 양식

```markdown
# 판례_[성공/실패/개선]_[사건명]_[번호]

## 사건명
## 결과
## 성공(실패) 이유
## 적용 기준   (앞으로 적용할 교훈 한 문장)

## 이행 추적
| 반영할 지침 | 반영 내용 | 상태 | 확인일 |
|---|---|---|---|
```

상태가 '대기'인 항목이 있으면 미종결이다. 이행확인심판(헌법재판소법 제11조의2)으로 반영 여부를 확인한 뒤 종결한다.
