# 판례_실패_무맥락템플릿해설_001

## 사건명

자동 생성 해설에서 "문제에서 묻는 조건과 맞지 않으므로 틀림", "최종 출력값 또는 계산 결과에 해당하므로 정답임" 같은 무맥락 템플릿 문장이 대량으로 삽입된 사례. (근거: 08_운영기록/시행보고의 정의·오답비교 재작성 보고, 리포트의 explanation 검수 산출물)

## 결과

- 실패 판정. 해당 문장은 도메인 지식 없이 어느 문제에나 붙일 수 있어 수험생이 개념을 배울 수 없었다.
- 정의·오답비교 재작성으로 각 보기의 고유 개념을 설명하도록 전면 수정.

## 실패 이유

- 정답·오답을 문제의 실제 개념이 아니라 "조건에 맞음/안 맞음"이라는 공허한 판정으로 서술.
- 중간 과정 생략 후 결과값만 기재.

## 적용 기준 (교훈 한 문장)

해설은 각 보기의 고유 개념을 도메인 지식으로 설명해야 하며, 아무 문제에나 끼워 맞출 수 있는 템플릿 문장은 실패로 처리한다.
