# 07_유권해석 안내

이 폴더는 기존 지침으로 판단이 안 되는 애매한 상황에 대해, 사용자에게 질문하고 받은 답을 해석으로 고정한 기록을 보관한다. (마스터프레임워크 7.2)

## 언제 만드나

- 기존 지침에 기준이 없다 / 지침끼리 다르게 해석된다 / 점수표로 판단이 어렵다 / 예외 허용 여부를 정해야 한다 / 반복될 가능성이 높다.

## 절차

```text
애매한 상황 → 관련 법률·시행령·시행규칙 확인 → 관련 판례·유권해석 확인
→ 기존 유권해석 있으면 그 기준 적용
→ 없으면 사용자에게 질문 (A안/B안/추천안, 1~3개)
→ 답변을 이 폴더에 유권해석 문서로 저장
→ 관련 지침·changelog 업데이트
```

## 유권해석 파일 양식

```markdown
# 유권해석_[분야]_[쟁점명]_v1.0

## 0. 문서 정보 (등급: 유권해석 / 작성일 / 관련 상위 문서 / 반영 상태)
## 1. 애매한 상황
## 2. 기존 지침 검토 (적용 가능 / 부족한 기준 / 충돌 가능성)
## 3. 사용자 질의 (질문 원문)
## 4. 사용자 답변 (원문에 가깝게)
## 5. 최종 해석
## 6. 적용 조건
## 7. 적용하지 않는 경우
## 8. 관련 지침 업데이트 (문서별 수정 여부)
## 9. 이후 적용 기준
## 10. 개정 이력
```

## 승격

같은 쟁점 유권해석이 3회 이상 반복되면 승격심판(헌법재판소법 제12조)으로 시행규칙 또는 법률로 올린다.
