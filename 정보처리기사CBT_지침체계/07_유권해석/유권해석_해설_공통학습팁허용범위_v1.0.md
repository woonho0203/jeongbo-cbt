## 1. 애매한 상황

자동 점검(고시 제2조의3-B)이 "같은 파일 안에서 해설의 마지막 문장이 3회 이상 글자 그대로 반복되는" 문항 **1,395건**을 무맥락 템플릿 후보로 적발했다. 대부분 유형별 카테고리(`category_keyword` 258건, `category_wrong-sentence` 197건 등)와 2017~2020 회차다.

문제는 이 문항들의 성격이 갈린다는 점이다.

```text
- 개념 정의: LSP는 하위 타입 객체가 상위 타입 객체를 대체해도 …   ← 문항 고유의 정확한 정의
- 정답 분석: 문제의 핵심 단서 "…"가 LSP의 정의와 일치함            ← 문항 고유
- 오답 분석:
  - 1번 ISP: ISP는 클라이언트가 사용하지 않는 인터페이스에 …       ← 보기별로 실제 다른 정의
  - 2번 DIP: DIP는 상위 모듈과 하위 모듈이 구체 클래스가 아니라 … ← 보기별로 실제 다른 정의
- 주의(함정): 유사 문제에서는 문제문에 제시된 핵심 단어를 …        ← 유형 내 모든 문항에 동일
```

본문은 문항마다 다르고 도메인 지식을 담고 있는데, **마지막 "주의(함정)" 학습 팁 줄만 유형 내에서 공통**이다. 이것을 헌법 제5조 3호가 금지한 "도메인 지식 없이 아무 문제에나 끼워 맞출 수 있는 무맥락 템플릿형 해설"로 볼 것인가?

## 2. 기존 지침 검토

- 헌법 제5조 3호: 무맥락 템플릿형 해설 금지. 판단 기준은 "도메인 지식 없이 아무 문제에나 끼워 맞출 수 있는가".
- 해설작성법 제5조 1호: 같은 금지를 반복하며 예시로 "문제에서 묻는 조건과 맞지 않으므로 틀림" 등을 든다.
- 고시_해설형식 제4조: 절대 금지 문장 목록. 여기에 "주의(함정)" 계열 학습 팁은 없다.
- **부족한 기준**: 해설의 *일부 줄*만 공통일 때 어떻게 판정할지에 대한 규정이 없다. 기존 지침은 해설 전체가 템플릿인 경우만 상정했다.

즉 반복되는 것은 말미 학습 팁 한 줄뿐이고, 정답 근거와 오답 분석은 전부 문항 고유의 도메인 내용이다.

다만 같은 검수에서 **정의 줄 자체가 문제 문장을 그대로 되풀이하는 동어반복 54건**이 별도로 드러났다. 예: `클래스는 "객체지향 소프트웨어 공학에서 하나 이상의 유사한 객체들을 묶어서 하나의 공통된 특성을 표현한 것은"에 해당하는 개념임.` 이것은 도메인 지식이 0이다.

## 4. 최종 해석

**해설의 말미에 붙는 유형별 공통 학습 팁 한 줄은 헌법 제5조 3호 위반이 아니다.** 헌법이 금지한 것은 "도메인 지식 없이 아무 문제에나 끼워 맞출 수 있는 해설"이며, 정답 근거와 오답 분석이 문항 고유의 내용을 담고 있다면 말미의 공통 학습 팁은 교재에서도 흔히 쓰이는 정형화된 마무리로 본다.

**단, 다음은 위반이다.**

1. **정답 근거나 오답 분석 자체가 공통 문구인 경우** — 판례_004의 "고정 커넥터형"이 여기 해당한다.
2. **정의·근거 줄이 문제 문장을 그대로 되풀이하는 동어반복** — `X는 <문제 문장>에 해당하는 개념임` 형태. 정의를 가장했을 뿐 도메인 지식이 없다.

## 5. 적용 조건

판정 순서:

```text
1. 마지막 줄을 제외한 본문이 문항별로 고유한가?  → 아니면 위반 (판례_004 유형)
2. 정의·근거 줄이 stem을 30자 이상 그대로 복사하고 '~에 해당하는 개념임'으로 끝나는가? → 그러면 위반
3. 오답 분석이 보기별로 실제 다른 내용을 담는가? → 아니면 보완 대상
4. 위 셋을 통과하면 말미 공통 학습 팁은 허용
```
