## 제1조 전체 절차

```text
1. 백업 확인 (git status)
2. 대상·매핑 확인 (JSON ↔ PDF 매핑표, 신규/재추출 모드 결정)
3. 자동 추출 실행 (scripts — 경로 정정 후)
4. 문항 객체 구성·정규화 (원 숫자 변환, 과목 부여, 필드 채움)
5. 자동 점검 (문항 수·필드·answer 범위·JSON 파싱·보존 diff)
6. PDF 원본 1:1 대조 검수 (04_시행규칙 채점표)
7. 앱 화면 확인
8. 판정·기록 또는 재작업 회귀
```

## 제2조 단계별 입력과 출력

| 단계 | 입력 | 출력 | 다음 단계 조건 |
|---|---|---|---|
| 1 백업 확인 | 현재 작업 트리 | 변경 전 상태 기록 | 변경 대상 파일 확인 완료 |
| 2 대상·매핑 확인 | PDF 폴더, 기존 JSON | 대상 회차 목록, 신규/재추출 모드 | 매핑표에 대상 존재 |
| 3 자동 추출 | PDF, 추출 스크립트 | 문항 초안 (stem·options·answer) | 산출물 생성, 스크립트 오류 0 |
| 4 구성·정규화 | 문항 초안 | 완성 문항 객체 | 필수 필드 전부 채움 |
| 5 자동 점검 | 수정된 JSON | 문항 수·필드·파싱·보존 점검 결과 | 오류 0건 |
| 6 원문 대조 검수 | JSON, PDF | 문제별 점수·판정 | 85점 이상 & 치명 오류 0 |
| 7 앱 확인 | 실행 앱 | 풀이/결과/오답/북마크 화면 확인 | 정상 렌더링 |
| 8 종료/재작업 | 채점 결과 | 회차 판정, 운영기록·changelog | 회차 판정 = 통과/조건부통과 |

## 제3조 신규 추출 / 재추출 모드

```text
신규 추출: 문항 객체가 없는 회차·유형 → 전 필드 생성. answer는 정답표 대조로 확정.
재추출:   기존 JSON 존재 → stem·options만 갱신.
          explanation·image·table·answer·메타 필드는 보존하고,
          갱신 전후 diff로 보존 필드 변경 0건을 확인한다. (문제추출법 제3조 5호)
```

## 제4조 회귀 기준

```text
자동 점검 오류(문항 수·필드·파싱·보존 diff) → 3~4단계로 회귀
문제별 85점 미만 또는 치명 오류 → 해당 문항 재추출(3단계)
번호 밀림 발견 → 해당 문항만 고치지 않고 밀림 구간 전체를 재대조 (연쇄 오류)
앱 미표시·로딩 실패 → 즉시 수정 후 5단계부터 재수행
회차 평균 95점 미만 또는 실패 1개 이상 → 회차 재작업
```

## 제5조 산출물 기록

- 추출 결과: 추출 보고서 (08_운영기록/리포트, 양식은 05_고시)
- 대조 검수 결과: 문제별 점수·판정 보고서 (08_운영기록)
- 종료 시 changelog에 대상 회차·문항 수·모드(신규/재추출) 기록
