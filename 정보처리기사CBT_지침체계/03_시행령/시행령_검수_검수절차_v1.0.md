## 제1조 검수 종류와 대상

| 검수 종류 | 대상 | 채점표(04_시행규칙) |
|---|---|---|
| 해설 검수 | `explanation` | 해설 채점표 |
| 이미지·표 삽입 검수 | 삽입 `image`·`table` | 이미지표 채점표 |
| PDF 대조 검수 | JSON 자료 ↔ PDF 원본 | PDF 대조 채점표 |
| 문장·띄어쓰기 검수 | `stem`·`options`·`explanation` 문장 | 띄어쓰기 즉시수정 기준 |

## 제2조 해설 검수 절차

```text
1. JSON 정상 파싱 확인
2. answer가 options 범위 안인지 확인
3. 문항 긍정형/부정형 표시
4. 정답 보기 읽고 해설 첫 문장이 정답 핵심 이유인지 확인
5. 그림·표·코드·SQL·계산은 중간값·최종값 대조
6. 오답 정리가 정답 외 보기만 다루는지 확인
7. 앱에서 문제·결과 화면 렌더링 확인
8. 문제별 채점(100점) → 판정
```

## 제3조 이미지·표 / PDF 대조 검수 절차

```text
1. 자동 점검 명령으로 JSON·이미지 경로·표 HTML 확인 (05_고시)
2. 후보 목록과 실제 삽입 결과 비교
3. 각 문제를 PDF 원본과 1:1 대조해 100점 채점
4. 앱에서 풀이/결과/오답/북마크 화면 확인
5. 점수 보고서 작성 (운영기록)
6. 85점 미만 또는 치명 오류 → 재추출·재삽입 지시
7. 회차 평균·실패 개수로 회차 판정
```

## 제4조 문장·띄어쓰기 검수 절차

```text
1. 화면에 먼저 보이는 stem·options 우선 검수, 이후 explanation
2. 즉시 수정 대상(조사·부사어·명사구 붙음 등) 교정 (04_시행규칙 표)
3. 코드·SQL·수식·파일명·영문 식별자는 제외
4. 애매하면 원문 보존 + 검수 메모
5. 대량 수정 후 JSON 파싱·앱 확인
```

## 제5조 단계 이동·회귀 조건

| 상황 | 처리 |
|---|---|
| 자동 점검 오류(파싱·경로·HTML) | 즉시 수정 후 재점검 |
| 문제별 실패/재검수 | 해당 문항 원문·PDF 대조 → 해설/자료 수정(시행령: 해설·추출삽입 절차) |
| 치명 오류 | 회차 판정 보류, 즉시 수정 |
| 회차 실패 1개 이상 또는 재검수 3% 초과 | 회차 재작업 |
| JSON 파싱 오류·앱 로딩 실패 | 즉시 재작업 |

## 제6조 산출물 기록

- 검수 결과: 회차·유형별 검수 보고서 (운영기록, 양식은 05_고시).
- 반복 오류 유형: 판례 후보.
- 승격 신호: 같은 쟁점 3회 이상 → 승격심판 청구 (헌법재판소법 제12조).
- changelog에 검수·수정 결과 기록.
