## 제1조 문제별 100점 채점표

| 항목 | 배점 | 채점 기준 |
|---|---:|---|
| 정답 정확성 | 30 | 해설 결론이 `answer`와 일치하고 개념 오류가 없는가 |
| 문제 의도 반영 | 20 | 긍정/부정형, "가장 옳은 것", "거리가 먼 것" 요구를 정확히 반영했는가 |
| 핵심 근거 | 20 | 공식·정의·계산값·출력값·방문 순서 등 정답 근거가 구체적인가 |
| 오답 정리 | 10 | 정답 외 보기들이 왜 아닌지 짧게 구분되는가 |
| 표현 품질 | 10 | 문장이 자연스럽고 맞춤법·띄어쓰기·조사 오류가 없는가 |
| 앱/JSON 적합성 | 10 | JSON 문자열과 앱 표시가 깨지지 않는가 |
| 합계 | 100 | |

## 제2조 점수별 처리

| 점수 | 판정 | 처리 |
|---:|---|---|
| 95~100 | 통과 | 수정 불필요 |
| 85~94 | 보완 | 짧은 문장 보강 |
| 70~84 | 재검수 | 원문과 다시 대조 |
| 0~69 | 실패 | 해설 재작성 |

## 제3조 문제별 판정 (정성)

| 판정 | 기준 | 처리 |
|---|---|---|
| 통과 | 정답 이유 정확 + 보기 비교 충분 | 수정 불필요 |
| 보완 | 핵심 맞으나 짧거나 오답 정리 약함 | 해설만 보강 |
| 재검수 | 정답 근거 불명확 또는 그림·표·코드 값 미확인 | 원문/PDF/앱 대조 |
| 실패 | 정답과 다른 설명·잘못된 개념·타 문제 해설·JSON 오류 | 즉시 수정 |

## 제4조 회차·유형별 판정

| 기준 | 판정 |
|---|---|
| 실패 0, 재검수 0, 보완 5% 이하 | 통과 |
| 실패 0, 재검수 3% 이하 | 조건부 통과 |
| 실패 1개 이상 또는 재검수 3% 초과 | 재작업 |
| JSON 파싱 오류 또는 앱 로딩 실패 | 즉시 재작업 |

## 제5조 치명 오류 (발견 즉시 실패)

- [ ] 정답 번호와 해설 결론이 다르다.
- [ ] 부정형 문제인데 정답 보기를 "맞는 설명"처럼 해설한다.
- [ ] **무맥락 템플릿형 해설이다.** (헌법 제5조 3호 — 판정 기준은 제5조의2)
- [ ] 다른 문제의 개념·다른 회차의 해설이 붙어 있다.
- [ ] 그림·표·코드에서 핵심 값·출력값·행/열·방문 순서가 실제와 다르다.
- [ ] 공식·용어 정의·표준 절차가 시험 범위와 다르다.
- [ ] 따옴표·줄바꿈·이스케이프 오류로 JSON 파싱이 깨진다.
- [ ] 앱에서 문제 상세·결과 화면이 열리지 않는다.

## 제5조의2 무맥락 템플릿 판정 기준 (승격 조항)

> 헌법 제5조 3호가 금지하는 무맥락 템플릿은 이 체계에서 **다섯 번 반복 적발**됐다(판례_001·003·004·005). 매번 리터럴 문구만 갱신하다 회피당했으므로, 헌재법 제12조에 따라 판정 기준 자체를 시행규칙으로 승격해 고정한다. 세부 탐지 명령은 05_고시(제2조의2·제2조의3)에 위임한다.

아래 순서로 판정한다. 하나라도 해당하면 **치명 오류(제5조)**다.

| 순서 | 검사 | 해당 시 |
|---|---|---|
| 1 | 해설 본문(말미 학습 팁 제외)이 같은 파일 내 다른 문항과 **글자 그대로 같은가** — 단, `stem`과 `options`가 동일한 **실제 중복 출제 문항은 제외**한다 | 위반 (고정 커넥터형 — 판례_004) |
| 2 | 정답 근거·오답 분석이 보기 내용과 무관한 **공통 문구**로만 채워졌는가 | 위반 |
| 3 | 정의·근거 줄이 문제 문장(stem)을 30자 이상 그대로 복사하고 `~에 해당하는 개념임` 류로 끝나는가 | 위반 (동어반복형) |
| 4 | 계산·코드·SQL형인데 **실제 계산값이나 실행 추적 없이** 단계 문구만 나열했는가 | 위반 (판례_005 중대 등급) |
| 5 | 05_고시 제4조의 절대 금지 문장을 포함하는가 | 위반 |

**허용**: 위 다섯을 모두 통과하면, 해설 말미에 붙는 **유형별 공통 학습 팁 한 줄**은 무맥락 템플릿으로 보지 않는다. (유권해석_해설_공통학습팁허용범위_v1.0)

**적용 원칙**: 금지 패턴을 새로 확인하면 05_고시의 탐지 명령을 갱신하되, **리터럴 문자열 목록에만 의존하지 않는다.** 위 1~4는 문구가 바뀌어도 성립하는 구조적 기준이다.

> 기준 1의 제외 단서는 실측에 근거한다. 한 회차 안에서 같은 문제가 과목을 달리해 두 번 출제되는 경우가 실제로 있다(exam_2023-1 Q1·Q23은 1과목과 2과목에, exam_2023-2 Q40·Q61도 마찬가지로 PDF 원본에 각각 출제됨). 이때 해설이 같은 것은 정상이므로 위반으로 보지 않는다.

## 제6조 유형별 필수 체크리스트

**부정형** — [ ] 해설이 "정답 보기가 왜 틀렸는지"로 시작 / [ ] "나머지는 맞는 설명" 성립
**계산** — [ ] 공식 포함 / [ ] 대입 과정 포함 / [ ] 결과 단위 일치
**코드** — [ ] 최종 출력값 명시 / [ ] 값 바뀌는 변수·반복 횟수 확인 / [ ] 전위·후위 증감·인덱스 확인
**SQL** — [ ] FROM→WHERE→GROUP BY/HAVING→SELECT→ORDER BY 흐름 / [ ] UNION vs UNION ALL 구분
**그림·표** — [ ] 자료에서 읽은 값 직접 기재 (트리 차수·순회, 그래프 방문 순서, 릴레이션 행/열, 세그먼트 물리주소, 스케줄링 값)
**키워드** — [ ] 결정 단서 ↔ 정답 용어 연결 / [ ] 유사 보기 차이 한 줄
**종류·순서** — [ ] 정답 순서 먼저 제시 / [ ] "외우면 된다"로 끝내지 않음

## 제7조 표현 감점 신호

- [ ] `정답입니다`만 있고 이유 없음 → 보완
- [ ] `나머지는 틀립니다`만 있고 오답 구분 없음 → 보완
- [ ] `그림을 보면 알 수 있습니다`만 쓰고 값 없음 → 보완
- [ ] `위와 같다`, `다음과 같다`처럼 원문 없이 모호 → 보완
- [ ] Markdown 제목·과도한 이모지·불릿으로 앱 화면 압박 → 감점

## 제8조 최종 완료 조건

- [ ] 자동 점검 명령(05_고시) 3개 통과 또는 확인 완료
- [ ] 실패 문항 0개
- [ ] 재검수 잔존 시 보고서에 사유 기록
- [ ] 앱에서 최소 1개 회차 + 1개 유형별 연습 해설 표시 확인
