## 제1조 치명 오류 (점수 무관 즉시 실패·재작업)

- [ ] 문항 수 불일치: PDF 문항 수 ≠ JSON 문항 수 (누락·중복 포함).
- [ ] 번호 밀림: 문제 본문이 다른 `qnum`에 배정되어 있다.
- [ ] 정답 불일치: `answer`가 PDF 공식 정답과 다르다.
- [ ] 보기 뒤바뀜: `options`의 순서나 내용이 PDF와 다르다.
- [ ] 타 출처 혼입: 다른 회차·다른 시험의 문제가 들어 있다.
- [ ] 보존 필드 유실: 재추출로 `explanation`·`image`·`table`·`answer`가 사라지거나 초기화됐다.
- [ ] 의미 변형: 오탈자·누락으로 문제·보기의 의미(정답 판단)가 달라졌다.
- [ ] JSON 파싱 오류·앱 로딩 실패.

## 제2조 문제별 채점표 (100점)

| 항목 | 배점 | 채점 기준 (PDF 대조 포인트) |
|---|---:|---|
| A. 문항 번호 매칭 | 15 | `qnum` ↔ PDF 번호, 번호 연속성 |
| B. stem 원문 일치 | 25 | PDF 문제 원문 ↔ `stem` 1:1 (요약·의역 없음) |
| C. options 원문·순서 일치 | 25 | PDF 보기 4개 ↔ `options` 내용·순서 1:1 |
| D. answer 공식 정답 일치 | 20 | PDF 공식 정답 ↔ `answer` (전항·복수정답은 배열) |
| E. 메타 필드 정확성 | 5 | `examId`·`title`·`subject`·`subjectName` 정확 |
| F. 형식·정규화 | 10 | 원 숫자 변환, 이스케이프, 공백, 코드 들여쓰기 |
| 합계 | 100 | |

## 제3조 감점 세부 기준

| 체크 | 감점 |
|---|---:|
| 의미가 변하지 않는 오탈자 (stem·options, 1건당) | −2~−5 |
| 의미가 달라지는 오탈자·누락 | 치명 오류 (제1조) |
| 특수문자·기호 깨짐 (→, ⊃, ≠, 첨자 등) | −3~−10 |
| 코드·SQL의 들여쓰기·줄바꿈 손상 (실행 의미 유지 시) | −5~−15 |
| 코드·SQL의 실행 의미가 달라지는 손상 | 치명 오류 |
| 불필요 문자열 혼입 (페이지 번호·머리글·저작권 문구) | −5~−10 |
| 부정형 강조 표시(밑줄·굵게) 소실이 문맥으로 복구 불가 | −3~−5 |
| 공백·줄바꿈 정리 미흡 (가독성 저해) | −2~−5 |

## 제4조 자동 점검 체크리스트 (하급 모델 위임 가능)

판단 없이 실행하는 항목. 하나라도 실패하면 `[심판: 필요]`로 표시하고 상급 검수로 넘긴다.

- [ ] 문항 수 = PDF 문항 수 (기출 회차는 100문항).
- [ ] `qnum`이 1부터 연속이고 중복이 없다.
- [ ] 필수 필드가 전부 존재한다. (데이터관리법 제2조 3호)
- [ ] `answer`가 정수 또는 배열이고, 값이 1 이상 `options` 개수 이하다.
- [ ] `options` 개수가 PDF와 같다 (기본 4개).
- [ ] JSON 정상 파싱, 앱 해당 회차 로딩 성공.
- [ ] 재추출 시: 갱신 전후 diff에서 `explanation`·`image`·`table`·`answer` 변경 0건.

## 제5조 문제별 판정

| 점수 | 판정 | 처리 |
|---:|---|---|
| 95~100 | 통과 | 수정 불필요 |
| 85~94 | 조건부 통과 | 사소한 표기만 보정 |
| 70~84 | 재검수 | PDF 원본과 다시 대조 |
| 0~69 | 실패 | 해당 문항 재추출 |

## 제6조 회차별 판정

| 기준 | 판정 |
|---|---|
| 평균 95점 이상, 실패 0, 치명 오류 0 | 통과 |
| 평균 90점 이상, 실패 0, 치명 오류 0 | 조건부 통과 |
