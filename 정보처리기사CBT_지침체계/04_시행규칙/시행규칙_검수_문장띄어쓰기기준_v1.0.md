## 제1조 검수 대상과 우선순위

- 대상: `questions[].stem`, `questions[].options[]`, `questions[].explanation`
- 우선순위: 화면에 먼저 보이는 `stem`·`options`를 먼저, 그다음 `explanation`.

## 제2조 핵심 원칙

1. 원문 의미·정답 번호·보기 순서는 바꾸지 않는다.
2. 붙어 있는 조사·어미·부사어만 자연스럽게 띄어 쓴다.
3. 전문 용어 내부 표기는 임의로 바꾸지 않는다.
4. 코드·SQL·수식·파일명·명령어·영문 식별자는 교정 대상에서 제외한다.
5. 일부러 붙여 쓴 용어인지 애매하면 원문을 보존하고 검수 메모로 남긴다.

## 제3조 즉시 수정 대상

| 유형 | 나쁜 예 | 좋은 예 |
|---|---|---|
| 조사 붙음 | 정의에서부터시작하여 | 정의에서부터 시작하여 |
| 부사어 붙음 | 점차구체화하여 | 점차 구체화하여 |
| 명사구 붙음 | 범위정의 | 범위 정의 |
| 동사 연결 붙음 | 구현해간다 | 구현해 간다 |
| 괄호 뒤 조사 붙음 | 프로젝트(Project)의특징 | 프로젝트(Project)의 특징 |
| 문장 중복 공백 | 기능 추가  쉽다 | 기능 추가가 쉽다 |
| 어색한 OCR 띄어쓰기 | 이 러한 모듈 | 이러한 모듈 |

## 제4조 교정 제외 (보존)

- [ ] 코드/SQL 블록 내부 공백·줄바꿈·들여쓰기
- [ ] 수식, 파일명, 명령어, 영문 식별자
- [ ] 전문 용어 고유 표기 (예: 붙여 쓰는 것이 표준인 용어)
- [ ] 일부러 붙여 쓴 것인지 애매한 경우 → 원문 유지 + 메모

## 제5조 완료 조건

- [ ] `stem`·`options` 즉시수정 대상 0건
- [ ] 원문 의미·정답·보기 순서 불변 확인
- [ ] 대량 수정 후 JSON 파싱 점검·앱 확인 완료
