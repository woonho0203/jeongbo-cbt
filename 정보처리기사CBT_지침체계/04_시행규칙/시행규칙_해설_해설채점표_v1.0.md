## 제1조 문제별 100점 채점표

| 항목 | 배점 | 채점 기준 |
|---|---:|---|
| 정답 정확성 | 30 | 해설 결론이 `answer`와 일치하고 개념 오류가 없는가 |
| 문제 의도 반영 | 20 | 긍정/부정형, "가장 옳은 것", "거리가 먼 것" 요구를 정확히 반영했는가 |
| 핵심 근거 | 20 | 공식·정의·계산값·출력값·방문 순서 등 정답 근거가 구체적인가 |
| 오답 정리 | 10 | 정답 외 보기들이 왜 아닌지 짧게 구분되는가 |
| 표현 품질 | 10 | 문장이 자연스럽고 맞춤법·띄어쓰기·조사 오류가 없는가 |
| 앱/JSON 적합성 | 10 | JSON 문자열과 앱 표시가 깨지지 않는가 |
| 합계 | 100 | |

## 제2조 점수별 처리

| 점수 | 판정 | 처리 |
|---:|---|---|
| 95~100 | 통과 | 수정 불필요 |
| 85~94 | 보완 | 짧은 문장 보강 |
| 70~84 | 재검수 | 원문과 다시 대조 |
| 0~69 | 실패 | 해설 재작성 |

## 제3조 문제별 판정 (정성)

| 판정 | 기준 | 처리 |
|---|---|---|
| 통과 | 정답 이유 정확 + 보기 비교 충분 | 수정 불필요 |
| 보완 | 핵심 맞으나 짧거나 오답 정리 약함 | 해설만 보강 |
| 재검수 | 정답 근거 불명확 또는 그림·표·코드 값 미확인 | 원문/PDF/앱 대조 |
| 실패 | 정답과 다른 설명·잘못된 개념·타 문제 해설·JSON 오류 | 즉시 수정 |

## 제4조 회차·유형별 판정

| 기준 | 판정 |
|---|---|
| 실패 0, 재검수 0, 보완 5% 이하 | 통과 |
| 실패 0, 재검수 3% 이하 | 조건부 통과 |
| 실패 1개 이상 또는 재검수 3% 초과 | 재작업 |
| JSON 파싱 오류 또는 앱 로딩 실패 | 즉시 재작업 |

## 제5조 치명 오류 (발견 즉시 실패)

- [ ] 정답 번호와 해설 결론이 다르다.
- [ ] 부정형 문제인데 정답 보기를 "맞는 설명"처럼 해설한다.
- [ ] 다른 문제의 개념·다른 회차의 해설이 붙어 있다.
- [ ] 그림·표·코드에서 핵심 값·출력값·행/열·방문 순서가 실제와 다르다.
- [ ] 공식·용어 정의·표준 절차가 시험 범위와 다르다.
- [ ] 따옴표·줄바꿈·이스케이프 오류로 JSON 파싱이 깨진다.
- [ ] 앱에서 문제 상세·결과 화면이 열리지 않는다.

## 제6조 유형별 필수 체크리스트

**부정형** — [ ] 해설이 "정답 보기가 왜 틀렸는지"로 시작 / [ ] "나머지는 맞는 설명" 성립
**계산** — [ ] 공식 포함 / [ ] 대입 과정 포함 / [ ] 결과 단위 일치
**코드** — [ ] 최종 출력값 명시 / [ ] 값 바뀌는 변수·반복 횟수 확인 / [ ] 전위·후위 증감·인덱스 확인
**SQL** — [ ] FROM→WHERE→GROUP BY/HAVING→SELECT→ORDER BY 흐름 / [ ] UNION vs UNION ALL 구분
**그림·표** — [ ] 자료에서 읽은 값 직접 기재 (트리 차수·순회, 그래프 방문 순서, 릴레이션 행/열, 세그먼트 물리주소, 스케줄링 값)
**키워드** — [ ] 결정 단서 ↔ 정답 용어 연결 / [ ] 유사 보기 차이 한 줄
**종류·순서** — [ ] 정답 순서 먼저 제시 / [ ] "외우면 된다"로 끝내지 않음

## 제7조 표현 감점 신호

- [ ] `정답입니다`만 있고 이유 없음 → 보완
- [ ] `나머지는 틀립니다`만 있고 오답 구분 없음 → 보완
- [ ] `그림을 보면 알 수 있습니다`만 쓰고 값 없음 → 보완
- [ ] `위와 같다`, `다음과 같다`처럼 원문 없이 모호 → 보완
- [ ] Markdown 제목·과도한 이모지·불릿으로 앱 화면 압박 → 감점

## 제8조 최종 완료 조건

- [ ] 자동 점검 명령(05_고시) 3개 통과 또는 확인 완료
- [ ] 실패 문항 0개
- [ ] 재검수 잔존 시 보고서에 사유 기록
- [ ] 앱에서 최소 1개 회차 + 1개 유형별 연습 해설 표시 확인
