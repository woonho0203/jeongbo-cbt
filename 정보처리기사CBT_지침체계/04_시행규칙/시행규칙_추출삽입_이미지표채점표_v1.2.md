## 제1조 공통 치명 오류 (점수 무관 즉시 실패·재작업)

- [ ] 오매칭: 다른 문제의 이미지·표가 붙어 있다.
- [ ] 핵심 값 잘림: 풀이에 필요한 숫자·라벨이 잘렸다.
- [ ] 앱 미표시: 이미지·표가 앱에서 전혀 보이지 않는다.
- [ ] 이물질 혼입: 정답표·해설 페이지·광고·저작권 문구가 자료로 들어갔다.
- [ ] 표 열 밀림: 헤더와 데이터 열이 밀려 정답이 달라질 수 있다.
- [ ] JSON 파싱 오류: 앱이 해당 회차를 불러오지 못한다.
- [ ] 자료 필요 누락: `stem`이 그림·표·트리 등 PDF 자료를 전제로 하는데 `image`·`table`이 모두 없다.
- [ ] 원본 표 평탄화: PDF의 행·열 표 또는 표처럼 정렬된 자료가 `stem`·`options` 줄글로만 들어가고 `image`·`table`이 없어 행·열 구조를 잃었다.
- [ ] 미승인 복합 자료: 원본 재현 근거·허용 목록 없이 `image`와 `table`을 동시에 사용한다.
- [ ] 복합 자료 중복: 승인된 예외라도 `image`와 `table`이 같은 정보를 반복해 화면을 이중 표시한다.

## 제2조 (A) 삽입 자체 검수 채점표 (100점)

| 항목 | 배점 | 채점 기준 |
|---|---:|---|
| 문제 번호 매칭 | 25 | PDF 자료가 정확한 `qnum`에 붙었는가. PDF 인쇄 번호가 다를 때는 `stem` 핵심 문구로 보정 매핑했는가 |
| 자료 완전성 | 20 | 그림/표의 필요 영역이 빠짐없이 들어갔는가 |
| 가독성 | 15 | 글자·숫자·선·화살표가 충분히 읽히는가 |
| 불필요 영역 제거 | 10 | 다른 문제·페이지 번호·저작권이 섞이지 않았는가 |
| 앱 렌더링 | 15 | 풀이/결과/오답/북마크 화면에서 정상 표시되는가 |
| 데이터 형식 | 10 | `image` 경로·`table` HTML 형식이 올바르고, 복합 자료면 승인 예외인가 |
| 해설 연계 | 5 | 해설이 이미지/표의 핵심 값을 반영하는가 |
| 합계 | 100 | |

## 제3조 (B) PDF 대조 채점표 (100점)

### 3-1. 이미지 문제

| 항목 | 배점 | PDF 대조 포인트 |
|---|---:|---|
| A. PDF 문제 번호 매칭 | 30 | `qnum` ↔ PDF 번호·`stem` 일치. PDF 인쇄 번호와 JSON `qnum`이 다르면 `stem` 기반 보정 근거가 있는지 확인 |
| B. 이미지 영역 완전성 | 25 | PDF 그림 범위 ↔ PNG 크롭 범위 |
| C. 가독성·해상도 | 20 | PDF 원본 대비 PNG 선명도·크기 |
| D. 불필요 영역 제거 | 15 | 인접 문제·페이지 번호·저작권 없음 |
| E. 파일명·경로 규칙 | 10 | `images/{examId}_q{qnum}.png` 형식 |
| 합계 | 100 | |

이미지 추가 감점: 좌우 여백 20% 초과 −3~−7 / 세로 150px 미만 −5~−10 / 파일명 `qnum` 불일치 −5 / 중복 저장 −2.

### 3-2. 표 문제

| 항목 | 배점 | PDF 대조 포인트 |
|---|---:|---|
| A. PDF 문제 번호 매칭 | 20 | `qnum` ↔ PDF 번호·`stem` 일치 |
| B. 행·열 구조 일치 | 30 | PDF 행 수·열 수·헤더 위치 ↔ HTML |
| C. 값 정확성 | 30 | PDF 셀 값 ↔ HTML 셀 값 1:1 |
| D. HTML 유효성 | 10 | `<table><tr><th>/<td>` 구조 |
| E. image 교체 판단 | 10 | HTML 표로 표현 불가능한 구조인지 |
| 합계 | 100 | |

값 정확성 세부 감점: 숫자 오탈자 1개 −5 (3개 이상 또는 핵심 숫자 오류 시 0점).

## 제4조 이미지 추가 체크 (감점)

| 체크 | 감점 |
|---|---:|
| 너무 작아 글자 흐림 | −3~−10 |
| 여백 과다로 모바일에서 작게 보임 | −3~−7 |
| 선/화살표/노드 일부 잘림 | −5~−20 |
| 파일명이 문제 번호와 불일치 | −5 |
| PDF 인쇄 번호만 믿고 JSON `qnum` 보정 근거를 남기지 않음 | −5~−15 |
| 같은 이미지 중복 저장 | −2 |

## 제5조 표 추가 체크 (감점)

| 체크 | 감점 |
|---|---:|
| 헤더-데이터 열 밀림 | 치명 오류 |
| 행 순서가 PDF와 다름 | −10~−20 |
| 빈 셀 사라져 의미 달라짐 | −10~−20 |
| 숫자/문자 오탈자 | −5~−20 |
| 셀 병합 구조가 중요한데 HTML로 평탄화 | −10 또는 실패 |
| HTML 표보다 이미지가 적합한데 HTML로 넣음 | −5~−15 |
| PDF 표를 `stem`·`options` 줄글로만 평탄화 | 치명 오류. 단, 행·열 구조가 정답 판단에 불필요함을 PDF 대조로 확인한 경우만 정상 예외 기록 |

## 제7조 회차별 판정

| 기준 | 판정 |
|---|---|
| 평균 95점 이상, 실패 0, 치명 오류 0 | 통과 |
| 평균 90점 이상, 실패 0, 치명 오류 0 | 조건부 통과 |
| 평균 90점 미만 또는 실패 1개 이상 | 재작업 |
| 치명 오류 1개 이상 | 즉시 재작업 |

## 제7조의2 복합 자료 예외 체크리스트

- [ ] 해당 문항이 스키마 고시의 복합 자료 허용 목록에 있다.
- [ ] 자기 독립 원본 PDF에서 `image`와 `table`이 모두 필요한 근거를 확인했다.
- [ ] 두 필드가 서로 다른 필수 정보를 보완하며 같은 내용을 단순 반복하지 않는다.
- [ ] 풀이·결과·오답·북마크 화면에서 표시 순서와 크기가 정상이다.
- [ ] 운영기록에 원본 대조 근거와 예외 유지 사유를 남겼다.

## 제7조의3 PDF 표-텍스트 평탄화 후보 판정

- [ ] 자동점검 고시의 평탄화 후보 목록을 확인했다.
- [ ] 후보 문항을 자기 독립 원본 PDF와 대조했다.
- [ ] 원본의 행·열 구조, 헤더, 셀 순서, 빈 셀, 단위가 정답 판단에 필요한지 확인했다.
- [ ] 구조가 필요하면 `table` HTML 또는 `image`로 복원하고, `stem`·`options`에는 문제 문장과 보기만 남겼다.
- [ ] 구조가 필요 없고 줄글 전사가 원본 의미를 보존하면 운영기록에 정상 예외로 남겼다.
